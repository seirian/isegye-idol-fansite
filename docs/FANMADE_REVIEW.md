# 팬메이드 — 신규 메뉴 검토본

사용자 승인: 기존 팬 창작관 제안으로 구현하되 메뉴명을 **팬메이드**로 변경.
브랜치 `feature/fanmade`, 기준 main `7542c84466d87632d45baa5251a8e74781c58259`.
검토 주소: https://isegye-idol.kr/review-fanmade/
기존 검토 경로처럼 관리자 로그인 후 열람한다. 화면과 기능은 일반 팬을 위한 메뉴이다.

## 제공 화면

- 작품 목록: 팬아트·팬영상·만들기, 멤버별 필터, 작품·창작자·키워드 검색, 제목순, 더 보기.
- 작품 상세: 원래 비율을 의도한 미리보기 영역, 여러 이미지 선택·이전/다음, 크게 보기와 키보드 조작, 작품 이야기.
- 창작자: 해당 창작자의 작품 모아보기. 상세에서 다른 작품으로 이동.
- 테마 전시: 노래가 그림이 될 때 / 여섯 가지 시선 / 손으로 만든 이세계. 명시적인 전시 ID로 작품 연결.
- 담은 작품: 추가·취소, 새로고침 유지, 저장 불가 안내. 기존 운영 저장함은 읽거나 수정하지 않는다.
- 상세·전시 고유 링크 공유: 복사 권한이 없으면 입력칸에서 직접 복사. 목록 복귀 때 기존 필터 유지.

## 예시와 실제 수록의 경계

12개 작품·4명 창작자·3개 전시가 **전부 검토용 예시**이며 카드와 상단에 표시한다.
외부 팬아트·영상·창작자 정보를 수집하거나 허락을 받았다고 주장하지 않는다.
원작 URL·공개일은 null이고 원작 버튼은 미등록으로 비활성화한다. 미리보기는 CSS 자리표시자이며 영상 재생을 가장하지 않는다.
실제 작품 공개·업로드·신고 접수·댓글·좋아요 집계·인기 순위·판매는 미구현이다.
동의받은 자료가 준비되면 별도 검증과 콘텐츠 등록 절차가 필요하다. 이번 빌더는 실제 작품 혼입을 거부한다.
운영 저장함 통합은 운영 반영 승인 시 별도 진행한다. 현재 저장은 `isegye:fanmade:review:v1` 하나로 분리한다.

## 운영 보호

main/develop에 커밋하거나 병합하지 않는다. 기존 운영 릴리스·메뉴·CSS·데이터·수집 배치·회원 저장소를 바꾸지 않는다.
검토 HTML과 메타데이터만 `.review-fanmade`에 저장하고 관리자 보호 경로 하나를 추가한다.
현재 인증 런타임과 의존성의 바이트 일치를 확인한 뒤 기존 진입점만 새 불변 런타임으로 연결한다.
계정·비밀설정·실제 세션은 읽거나 쓰지 않는다. 기존 3개 검토 경로와 음반 API·권한 분리는 유지한다.
전역 배포 잠금과 중단 변수를 준수하고, 활성화 후 검증 실패 시 이전 진입점과 포인터를 복구한다.
폐기된 review-fan / review-2ndcheck를 복원하지 않는다. 공개 미러·기존 Pages 경로를 만들지 않는다.
해시 기반 CSP, 외부 요청 차단, noindex/noarchive, private/no-store를 적용한다.

## 빌드 및 검증

```sh
python scripts/build_fanmade.py
node --test tests/fanmade.test.js
python -m unittest discover -s tests -p test_fanmade.py -v
python tests/fanmade_browser.py
# 기존 auth 의존성 설치 후:
python scripts/build_fanmade_host.py
python tests/fanmade_host_browser.py
```

로컬 브라우저에서 HTTP가 차단될 때 `FANMADE_DOM_ONLY=true`는 DOM 동작만 검사하며 저장 지속성·실제 HTTP 결과를 주장하지 않는다.
게시 CI는 DOM 전용 모드를 사용하지 않고 HTTP 전체 기능 검사와 실제 로컬 TLS/PHP 가상 계정 권한 검사를 통과한 뒤에만 업로드한다.
실제 Google 계정을 대신 로그인하지 않는다. 실서버 확인은 파일 바이트·기존 운영 응답·익명 차단·경로 비노출 검사이다.
