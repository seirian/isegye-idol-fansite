# 운영 정보의 관리자 전용 표시

2026-11-16 사용자 요청: 상태 페이지와 사이트 전반에서 일반 이용자에게 필요 없는 운영 정보를 관리자만 보도록 분리합니다.

## 이용자 화면

상태 페이지의 출처·원문 링크·최종 확인 날짜는 유지합니다. 출처별 수집 성공 배지, 마지막 시도, 수집 상세 사유와 운영 연동 확인표는 관리자 영역으로 이동합니다. 확인 시각을 오늘로 바꾸거나 오래된 자료를 정상으로 표시하지 않습니다.

앨범/곡 상세의 순위 그래프·최고 기록·실제 출처·확인 날짜·스트리밍 연결·공식 달성 배지를 유지합니다. 서비스 API 연결 진단, 키 설정 안내, 배치 시간, 게시 시각, 누락 건수와 그래프 검토용 예시는 관리자 영역으로 분리합니다. 일반 이용자는 `?demo=1`로 예시 데이터를 열 수 없습니다. 최신 자료를 확인하지 못했거나 기록이 비어 있는 경우에는 이용자에게도 필요한 설명을 남깁니다.

콘텐츠/사이트소개의 채널별 수집 완료 수, 공지의 구현 예정 변경 이력, 일정의 수집 진단, 활동 기록의 운영 설명을 분리합니다. 홈과 음악 목록에 남아 있던 검토본 표현도 정리합니다. LIVE의 조회 실패·재시도, 출처 인용, 팬 자료 구분, 저작권·약관·개인정보 안내, 정정 제보, 개인 저장 기능은 일반 이용자에게 필요하므로 유지합니다.

## 권한 및 읽기 응답

- 일반 화면을 기본값으로 렌더링합니다. `/auth/status`가 authenticated/administrator/allowed 모두 true일 때만 별도 `/src/admin-operations.js` 모듈을 읽습니다.
- PHP Gateway는 실제 세션과 기존 Store의 관리자 판정으로 모듈과 `/build-info.json` 요청을 검사합니다. 쿼리, localStorage, DOM 속성을 권한으로 사용하지 않습니다. GET/HEAD만 허용하며 새 관리 쓰기 API는 만들지 않습니다.
- 같은 `/src/data.js`, 앨범 데이터, 기존 운영 UI의 내장 데이터와 runtime-feeds는 비관리자에게 공개용 파생 파일을 반환합니다. 원본 수집·게시 데이터와 관리자 응답은 변경하지 않습니다.
- `/api/schedule`, `/api/music`, `/api/history`, `/api/albums`의 비관리자 읽기 응답에서는 운영 진단 필드를 제외합니다. 값의 상태/차트 밖/실패 구분에 필요한 콘텐츠 필드와 출처·날짜는 유지합니다. 공개용 파일이 없으면 원본으로 되돌아가지 않습니다.
- JSON 공개화 정책은 `auth/public-view-policy.json`을 Python 빌드와 PHP 런타임이 공동 사용합니다. 관리자의 원본 JSON은 바이트 단위로 그대로 반환합니다.
- 게시 후 검증은 공개용 파생 응답의 정확한 바이트와 관리자 진단 경로의 401 거부를 별도로 대조합니다. 파일 재조회·백업·원자적 활성화·복구 안전장치는 유지합니다.
- 모든 응답의 기존 private/no-store/Vary: Cookie 설정, 로그인 검증, 120분 비활동/12시간 최대 만료, 점검 모드와 회원 저장소는 그대로 유지합니다.
- 권한 조회 실패/권한 상실/탭 숨김·이탈 시 관리자 표시를 제거합니다. 저장된 관리자 플래그를 재사용하지 않습니다. 기존 관리자 전용 검토판은 변경하지 않습니다.

## 검사

`tests/test_admin_visibility.py`: 실제 PHP 세션 저장소를 이용한 게스트/회원/관리자/만료 관리자 요청, 쿼리·URL 인코딩 권한 위조, GET/HEAD/POST, 점검 모드 보존, 파생 파일 선택·원본 역노출 방지 및 Python/PHP 공개화 결과 일치.

`tests/admin_visibility_browser.py`: 상태·홈·멤버·일정·공지·앨범·곡·영상·시리즈·활동·검색·저장·가이드·소개·약관·개인정보 등 30개 경로, 접힌 상세 내용, 일반/관리자 구분, 예시 쿼리, 권한 조회 실패·권한 상실, PC/모바일 및 기존 음악·외부 영상 연결. CI/운영 배포 전에는 HTTP 브라우저 검사를 실행합니다. IN_MEMORY 모드는 제한된 로컬 환경의 DOM 확인 전용이며 CI에서는 사용하지 않습니다.
