# 가독성·소개 페이지 개선 검토

브랜치 `feature/readability`, 운영 main과 backup/main1st는 변경하지 않습니다.

## 구현
- 기존 미세 글씨를 최소 14px(rem), 본문과 주요 조작을 16px 이상으로 조정.
- 행간, 텍스트 대비, 모바일 카드 배치, 버튼 영역을 함께 개선.
- 소개는 사이트 목적, 정보 제보, 최소 이용 안내의 세 영역만 노출.
- 파일명, 운영 소스 링크, 요청 이미지 경로, 접근 오류, 개발 브랜치와 검수 기술 설명을 소개/멤버 화면에서 제거.
- 공개 기록의 근거 출처와 비공식·권리자 안내는 유지.

## 아직 미완료: 최신 나무위키 이미지
2026-10-22 재확인 결과 원문 403, 미러의 여섯 프로필 이미지 503. 근거: Actions 39740585356의 portrait-check/report.json. 미러 텍스트를 최신 원본 이미지 확보로 간주하지 않습니다.

오래된 공식 아바타를 현재 프로필로 계속 표시하지 않기 위해 **새 검토본에만** 기존 이미지 파일을 제외하고 `최신 프로필 준비 중` 이름 카드를 표시합니다. 최신 이미지 교체 완료가 아닙니다. 원본 파일 6개 또는 접근 가능한 원본 URL을 확보하면 review/portraits.json의 검증 기록과 함께 적용합니다. 예전 이미지를 fallback으로 내려받지 않습니다.

## 실행
`python scripts/build_readability.py` → readability-dist/index.html, review.html.

새 workflow는 기존 develop 루트와 /second/를 보존하는 패키지에 /previews/feature-readability/만 추가합니다. main 병합, 인아워넷 배포, production 환경/Secret, DNS, 미르 경로는 사용하지 않습니다. 임의 feature 전체의 영구 보존 기능은 이 변경의 범위 밖입니다.

검토 승격 전 최신 이미지 요구사항과 브라우저 검증 결과를 반드시 확인해야 합니다.
