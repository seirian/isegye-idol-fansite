# 시간별 앨범 관측 데이터 용량

시간 단위 30일 차트 및 영상 관측을 유지하기 위해 운영 JSON 저장·API·브라우저 상한을 8,000,000바이트/문자로 일치시킨다. 산출물은 간결한 JSON으로 기록한다. 기존 2MB 상한은 26곡의 시간별 차트 이력과 호환용 중복 이력이 쌓이면 초과할 수 있다.

기존 30일·관측점 수 제한, 이미지 180KB 제한, ZIP 다운로드 8MB 상한, SFTP 읽기 9MiB 상한, 소유자·호스트키·로그인·배포 경계는 유지한다. 브라우저는 게시된 서버 응답만 읽으며 실제 원본 관측 시각을 바꾸지 않는다.

`test_album_hourly_capacity.py`는 26곡의 30일치 주간 관측 및 영상 이력을 합성해 2MB 초과/8MB 미만의 정상 자료 수용과 초과 자료 거부를 확인한다. 기존 승인된 UI 원본의 해시는 변경하지 않고, 운영 빌드에서 응답 크기 상한만 맞춘다.
