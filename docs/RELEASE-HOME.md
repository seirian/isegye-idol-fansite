# 심플 홈 운영 승격 (v0.5)

승인된 검토 커밋 `c770c9d590c9e46a86c55d91d02d28d27da6ac05`의 홈만 반영합니다.

- 기존 LIVE 코드·30초 조회·방송 썸네일과 실패 시 확인불가 처리를 그대로 유지합니다.
- 간단한 소개, 6명 바로가기, 최근 영상·음악 선택, 일정·활동 기록 연결과 제보 배너 제거를 운영에 적용합니다.
- 크롤러·예약 수집·DB 등 새로운 수집 기능은 추가하지 않습니다.
- 기존 카탈로그154개, 선택 영상151개, 연혁55개,21개 채널은 그대로 사용합니다. 기존 빌드 시 채널 갱신은 유지합니다.

`build_release_home.py`는 승인본 홈/LIVE 파일의 SHA-256을 검증하고 기존 미공개 빌드 산출물을 포장합니다. 검토 전용 빌더는 계속 noindex이며, main 전용 진입점에서만 공개 베타·canonical·검색 허용 정보를 적용합니다. 운영 패키지에 review.html은 포함하지 않습니다.

`develop`에 PR #8을 병합하고 Pages 실주소 검증 후, develop→main PR을 병합합니다. 배포 트랜잭션·SFTP 루트·시크릿·DNS는 바꾸지 않습니다. 새 홈 검사와 실제 화면 캡처도 기존 `verify_release_v04.py` 검증 경로를 통해 자동 원복 가능 구간 안에서 실행됩니다. 기존 기능 검사도 유지하고 홈 DOM이 달라진 선택자만 새 구조에 맞춥니다.

기존 `backup/main1st`는 원래 첫 운영 커밋을 그대로 보존합니다. 이전 운영 커밋은 `ecd43bdb0e994a2fe475324ef2f036663e706753`이며 이전 서버 릴리스와 라우터 백업도 보존합니다. 쓰기는 `/web/_isegye_idol` 내부로 제한되고 미르·공용 라우팅은 변경하지 않습니다.

개발 Pages 게시 시 `feature-home-simple` 경로도 함께 포함해 이번 승인본의 검토 주소가 사라지지 않게 합니다. 이는 범용 브랜치 자동 배포 시스템을 새로 구축하는 작업이 아닙니다. 최종 성공은 병합 상태가 아니라 운영 Actions의 `inour-report.json` 및 실제 게시 주소 검사 결과로 확인합니다.
