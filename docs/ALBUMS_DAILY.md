# 운영 앨범 정기 갱신

2026-11-10 사용자 승인: Across Dimensions와 5곡의 앨범 등록, 출처 연결, 운영 반영 및 정기 갱신을 수행한다. 기존 앨범 승격 문서의 정기 수집 미활성화 범위는 이 추가 승인에 한해 변경한다.

- `catalog/album-releases.json`에 멜론 앨범 15120216의 실제 트랙 순서·발매일과 공식 채널 영상 5개를 기록한다. 곡 ID를 추정하지 않고 실제 공개 앨범 응답에서 제목·아티스트·앨범을 대조한다.
- 승인된 154곡 기준 빌드 및 10개 앨범 UI 원본은 변경하지 않는다. 앨범 합성 단계에서 운영 카탈로그와 음악 피드의 기본 목록에 새 5곡·1앨범을 함께 추가한다. 영상 ID 기준으로 일배치 결과와 중복을 막는다.
- `albums-daily.yml`: 매일 07:13 KST(UTC 전일 22:13), 음악 갱신 성공 뒤 및 수동 실행. 실행 시각은 GitHub 예약 처리에 따라 지연될 수 있다. 기존 음악·일정·월간 활동기록 주기를 변경하지 않는다.
- 실제 공식 영상 메타데이터/썸네일을 검증한다. 필수 조건은 등록된 발매곡의 최신 멜론 정보, 새 앨범 5곡의 일치, 표지 및 최신 TOP100/HOT100 관측이다. 선택적 Apple US 메타데이터·YouTube 통계·지니·벅스 오류는 경고로 남긴다. 미제공 순위나 과거 순위는 만들지 않는다.
- 승인된 기존 수집기를 이용한다. 유료 서비스, 로그인/접근 제한 우회, 음원 다운로드는 하지 않는다. 공개 수집 단계에는 운영 SFTP 자격 증명을 전달하지 않는다.
- 현재 운영 릴리스/카탈로그 버전을 확인한 뒤 이전 운영 데이터와 이미지를 읽어 복원한다. 실패한 출처의 마지막 검증값과 원래 확인 시각을 보존하며 실패를 새 성공으로 표시하지 않는다. 필수 검증 실패 시 운영 스냅샷은 교체하지 않는다.
- 새 데이터는 `.albums-feed`의 소유자 표시·전용 잠금·이전 스냅샷 백업을 사용해 교체한다. 이미지·JSON을 다시 읽어 바이트를 검증한다. 라우터·계정 저장소·정적 릴리스는 수정하지 않는다.
- `/api/albums`와 해시로 지정된 표지 경로는 기존 Gateway 접근 검사를 통과한 뒤에만 읽는다. 유지보수 모드에서 비인가 접근은 기존과 동일하게 차단한다. 새로운 시각의 데이터가 승인된 화면에 반영되도록 운영 어댑터만 변경한다.
- PR 공개 출처 검증은 운영 자격 증명 없이 수행한다. CI는 기존 전체 테스트에 새 JSON/이미지 접근 권한·변조·심볼릭 링크·로그아웃 검사와 실제 브라우저의 최신 스냅샷/표지 반영 검사를 추가한다.

알림 또는 녹색 실행 표시만으로 성공을 판단하지 않는다. `albums-publication.json`의 `published`, `verifiedReadback`, 필수 출처 health와 실제 5곡 연결을 확인한다. 관측 그래프는 실제 수집한 시점만 누적하며 발매 이후 모든 시간의 순위를 복원했다고 표시하지 않는다.
