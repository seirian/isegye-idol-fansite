# 놀이터 — 일반 이용자 신규 메뉴 검토본

브랜치: `feature/playground`. 기준 main: `7542c84466d87632d45baa5251a8e74781c58259`.
검토 주소: https://isegye-idol.kr/review-playground/
기존 검토 경로와 동일하게 관리자 로그인 후 열람한다. 메뉴 자체는 일반 팬을 위한 콘텐츠다.

## 제공하는 기능

- 오늘의 5문제: 한국 날짜와 문제은행 버전으로 선정한다. 네 주제가 섞이고 같은 날에는 같은 문항이다. 제한된 문제은행에서 선정하므로 다른 날에도 반복될 수 있다.
- 취향대로 퀴즈: 음악·음반 8문항, 멤버·팬문화 10문항, 커버·유닛 8문항, 무대·이야기 6문항. 5/10문제를 선택하며 주제의 문항 수보다 큰 선택은 막는다.
- 먼저일까, 나중일까?: 최초 국내 음원 발매일이 확인된 5곡의 10개 조합 중 5라운드. 같은 날짜는 제외하고 MV 공개일과 섞지 않는다.
- 힌트, 건너뛰기, 즉시 정답·해설, 출처 펼쳐보기, 관련 운영 아카이브 연결. 시간제한과 팬 등급·공개 순위는 없다.
- 새로고침 후 이어풀기, 최근 20회 완료 기록, 틀리거나 건너뛴 문제 다시 풀기, 결과 텍스트 공유, 검토 기록 초기화.
- 키보드 답 선택, 다크 모드, 320/390/768/1440px 반응형 화면. 영상·이미지·음원 다운로드나 재생은 하지 않는다.

## 참고한 실제 자료와 검증의 경계

32개 문항은 실제 자료를 참고해 새 문장과 보기로 작성했다. 예시 팬 작품이나 가짜 정답은 없다.
`docs/PLAYGROUND_SOURCE_RECHECK.md`에 기록한 왁물원 두 지정 글의 본문·답안·정정 댓글을 사용한다.
소재 참고 문항 번호는 `inspiration`, 정답 판단에 사용한 자료는 `sources`, 자료의 확인 기준일은 `checkedAt`으로 구분한다.
커뮤니티 답안만으로 구성한 6개 문항은 공식 발표로 표시하지 않고 해설에 해당 기준을 알린다.
51번의 수정된 곡명은 기존 커버 카탈로그와 대조했다. 정답 충돌이 지적된 25번과 개인 취향 20·21번은 제외했다.
이전 판본 21702194는 최종본과 독립 자료나 추가 문항으로 중복 집계하지 않았다.

나무위키는 기존 멤버·커버 카탈로그에 보존된 자료를 참고한다. 2026-10-23 확인 기준과 원본 링크를 표시하며 이번 직접 접근으로 본문 전체를 다시 읽었다고 하지 않는다.
직접 재열람하지 못한 나무위키 그룹 문서는 `context`로 분류하고 정답 근거로 사용하는 것을 빌더가 거부한다.
멜론·벅스의 공개 곡/발매 소개와 음반 목록으로 발매 순서 및 OST 정보를 대조했다.
기존 카탈로그만 대조한 자료, 공개 원본 확인, 커뮤니티 답안은 화면에서 구분한다. 모든 문항이 새로 공식 출처 검증을 마쳤다고 주장하지 않는다.
원문 퀴즈·댓글 전문, 가사·음원·팬 이미지, 개인 사생활 자료는 배포하지 않는다.

## 저장과 운영 보호

`isegye:playground:review:v1` 한 키만 읽고 쓴다. 계정 동기화나 공개 기록은 없으며 운영 저장함/설정은 읽거나 수정하지 않는다.
저장 실패·손상 시 탭 안의 풀이를 유지하고 제한을 안내한다. 문제은행 버전이 바뀌면 오래된 기록을 안전하게 초기화한다.
검토 링크를 공유해도 다른 브라우저의 점수나 해설 기록은 노출되지 않는다. 공유 텍스트에는 검토 경로의 관리자 열람 조건을 알린다.

main/develop, 운영 메뉴·CSS·API·배치·회원 저장소는 변경하지 않는다.
추가 게시 대상은 `.review-playground`의 검토 HTML/메타데이터와 이를 읽는 보호 경로 하나다.
기존 fanmade 검토본도 삭제 승인 없이 변경하지 않는다. 이미 게시된 FanmadePreview.php는 원본 바이트와 일치하는지 확인해 그대로 유지한다.
현재 인증 런타임의 기존 파일과 Gateway가 예상 기준과 일치할 때만 새 불변 런타임을 활성화한다. 기존 4개 검토 경로와 운영 릴리스 바이트를 게시 전후 비교한다.
기존 배포 잠금·중단 변수를 준수한다. 실패하면 진입점/포인터를 복구한다. 실제 계정·세션·비밀 설정을 읽거나 수정하지 않는다.
단일 HTML은 해시 CSP, 외부 요청 차단, private/no-store 및 noindex/noarchive로 제공한다.

## 검증

```sh
npm test
python scripts/build_playground.py
python -m unittest discover -s tests -p test_playground.py -v
python tests/playground_browser.py
python scripts/build_playground_host.py
python tests/playground_host_browser.py
```

로컬 실행환경에서 HTTP 탐색이 차단되면 PLAYGROUND_DOM_ONLY=true는 DOM 검사만 수행한다. 실제 HTTP 저장 지속성과 TLS/PHP 권한 검사는 CI에서 실행하고 통과해야 게시한다.
실서버의 실제 Google 로그인을 대신 수행하지 않는다. 게시 검증은 정확한 파일 해시, 기존 경로 응답, 비공개 경로의 접근 차단으로 수행한다.
