# 전체 개선안 1차 검토 — feature/review-1st

## 목적과 경계

기존 6개 상위 메뉴를 유지하고 공지·일정·음악·영상·멤버·활동 기록을 검색과 저장함으로 연결하는 **클릭 가능한 첫 검토본**이다. 운영용 앱을 교체하는 릴리스가 아니다. `main`, `develop`, 운영 인증·접근 제한·법률 문서·수집 배치·서버 파일을 변경하지 않는다.

검토 소스는 `review-1st/`, 빌더는 `scripts/build_review_1st.py`, 결과는 `review-1st-dist/`로 분리했다. 기존 `npm run build`의 운영 선택은 그대로다. 새 빌더는 production 환경 및 main/develop ref에서 실행을 거절한다. 워크플로는 feature/review-1st에서만 동작하며 배포용 자격 증명·공개 Pages 미러·운영 업로드가 없다.

## 보는 방법

- 별도 제공하는 `review.html`은 CSS, JavaScript, 검토 자료, 프로필·단체 사진을 포함한 독립 HTML이다. 저장해 브라우저에서 열고 상단의 **적용 범위·검토 안내**를 통해 각 화면으로 이동한다.
- 외부 썸네일·SOOP 방송 상태는 연결 가능할 때만 조회한다. 연결이 실패하면 원본 링크와 **상태 확인 필요**를 유지한다. 파일을 열었다고 방송 여부가 미리 검증된 것은 아니다.
- 첫 화면: `#/home`; 전체 범위 안내: `#/review`; 복구 공지 예시: `#/schedule?month=2026-11&date=2026-11-03&view=calendar`.
- 검토 저장함과 설정은 `isegye:review1:*` 키만 사용한다. 저장이 차단된 환경에서는 해당 탭에서만 유지한다고 안내한다. 운영 저장함·계정 동기화가 아니다.

## 로컬 빌드와 검증

```sh
# 기존 빌드에 필요한 Python 도구는 기존 프로젝트 절차 사용
npm run build
python scripts/build_review_1st.py
node --test tests/review_1st.test.js
python -m unittest discover -s tests -p test_review_1st.py -v
# 실제 로컬 서버를 사용할 수 있는 환경
python -m http.server 4198 --bind 127.0.0.1 --directory review-1st-dist
REVIEW_URL=http://127.0.0.1:4198/review.html python tests/review_1st_browser.py
```

브라우저 도구에 따라 `CHROMIUM_PATH`로 실행 경로를 지정할 수 있다. `REVIEW_URL`을 생략하면 정확한 독립 HTML을 메모리에서 렌더링하고 모든 외부 연결을 차단한다. 이 모드의 localStorage와 시계는 명시적 테스트 대역이며 실제 파일/HTTP 탐색, 브라우저 디스크 보존, 운영 서버 접속, 실제 SOOP 상태 확인의 증거가 아니다. 실제 검사 범위와 결과는 `test-results/review-1st/result.json`에 기록한다.

정규 GitHub 워크플로에는 로컬 서버를 통한 독립 HTML 검사가 포함되어 있으나, 워크플로 파일 존재만으로 그 실행이 성공했다고 말하지 않는다. 원격 커밋/CI/게시 여부는 별도로 확인해야 한다.

## 이번 검토에 포함하지 않은 운영 변경

새 크롤러 가동, 비공개 게시글 수집, 원문·댓글 복제, 팬 개인 분석, 계정/알림 서버, 실제 수정 이력 저장, 공연 세트리스트 생성, 공개 호스팅과 접근 정책 변경은 하지 않는다. 메인/디벨롭 병합 및 운영 반영은 이 검토 결과를 승인한 뒤 별도 작업이다.
