## 화면
- `입문·멤버`를 `멤버 소개`로 변경하고, 6명 카드와 상세 프로필을 새로 구성합니다. 기존 입문 순서·멤버 페이지의 팬 가이드 링크를 제거합니다.
- 상세에는 공개된 생년·생일, 소속 그룹/회사, 그룹 데뷔일/곡, 팬덤, 상징색과 출처를 표시합니다. 비공개 생일을 추정하지 않고 실제 신상·가족·거주지 정보는 수집하지 않습니다.
- 본채널·서브·다시보기·음악·게임 등 확인한 21개 연관 채널을 개별 구역으로 표시합니다. 각 채널의 공개 Atom 피드에서 published 기준 최신 3개를 제공하며 Shorts와 다시보기도 포함될 수 있습니다.
- 음악은 154개 항목(오리지널20, 커버133, 리메이크1)입니다. 메들리·오디션 영상이 있으므로 154개의 서로 다른 곡이라고 주장하지 않습니다. 재수록·반주 버전은 별도 항목으로 중복 집계하지 않습니다.
- 곡 종류, 개인/유닛/단체, 참여 멤버, 연도, OST/테마송·페스티벌·외부협업·오디션 필터를 조합합니다. 제목·앨범·멤버 검색과 날짜/제목 정렬, 24개씩 페이지를 제공합니다.
- 곡 상세에는 발매일/영상공개일 구분, 참여 멤버, 수록 음반·트랙, 출처·원본으로 연결합니다. 가사/음원 복제나 영상 자동재생은 하지 않습니다.

## 자료와 한계
2026-10-23 요청 문서의 namu.wiki 원문은 HTTP403으로 접근하지 못해 공개 namu.moe 미러를 확인했습니다. 화면에는 원문과 실제 확인한 미러를 함께 표기합니다. 문서 전체 서술을 복사하지 않고 기본 사실·곡/영상 메타데이터만 요약합니다.

근거 파일은 Inspect member and music sources 실행 39917741669, 채널 피드는 Inspect linked member upload feeds 실행 39918429331에 보관됩니다. 21개의 채널 ID와 각 공개 피드의 채널 식별자를 대조했습니다. 채널 목록은 출처가 확인된 범위이며 인터넷상의 모든 연관 채널을 망라한다고 주장하지 않습니다.

Be My Light는 미니 앨범으로 분류하며 재수록 3곡과 반주 2곡을 포함한 수록곡 정보를 상세에 제공합니다. Smile For You의 발매일은 미러의 연도 표기 대신 패러블 공식 자료의 2026-06-19를 따릅니다. 외부 협업은 참여 멤버를 별도로 확인해 모두 단체곡으로 취급하지 않습니다.

## 최신 영상 갱신
`refresh_catalog_videos.py`는 검토 빌드 때 21개 공식 YouTube Atom 피드를 요청합니다. 채널별 최대3개를 공개일순으로 보관하며 확인 시각을 화면에 표시합니다. 실시간 또는 매일 자동 갱신을 구현한 것은 아닙니다. 새 업로드는 다음 검토 빌드/수동 Actions 재실행 시 반영됩니다. 36시간 넘은 목록은 최신 채널을 직접 확인하도록 안내합니다.

피드 오류는 이전 성공 스냅샷과 원래 확인 시각을 보존하고 stale/unavailable로 표시합니다. 최신 수집 시각으로 과거 데이터를 덮어 표시하지 않습니다. API 키·비밀값·방문자 쿠키·공용 프록시는 사용하지 않습니다. 채널 ID/영상 ID/URL 및 XML 크기·선언을 제한합니다. 썸네일은 YouTube 이미지 서버에서 불러오므로 개인정보 안내와 CSP 허용 범위를 추가했습니다.
