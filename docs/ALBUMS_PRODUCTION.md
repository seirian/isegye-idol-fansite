# 승인된 앨범 최종본 운영 승격

사용자는 최종 검토 완료 후 develop 및 main 반영을 요청했습니다. 승인 UI 기준은 `feature/albums`의 `f2c00e2bb1f4a762e8ff1578f540584652d8053b`입니다. 이전 문서의 운영 미반영 제한은 이번 명시적 승격 승인으로 해제됩니다.

## 보존
- 승인된 10개 UI/스타일 소스의 SHA-256을 `albums/accepted.json`으로 검사합니다.
- 멜론 전용 곡선 그래프, 최고 성적 7종의 항목별 출처, 공식 앨범 달성 배지, 국내 표지, 무료 API 상태와 제거된 서비스 범위를 유지합니다.
- 전체 운영 영상 카탈로그와 기존 저장함·홈 기본 경로·일정/음악/활동기록 API를 유지합니다. 검토판의 제한된 영상 샘플은 운영에 사용하지 않습니다.
- `main`의 최신 영상 카탈로그 커밋 `58baff4ceba202dcfe69bcb9f2404bd0b196577e`를 보존합니다.
- 기존 관리자 인증, 회원 정책, 기존 검토 경로, 운영 배치와 스케줄을 변경하지 않습니다.

## 운영 구성
`promote_albums.py`가 완전한 기존 운영 빌드 위에 승인된 앨범 UI를 합성합니다. 검토 안내 배너를 제거하고 `/src/albums-insights.json`으로 동일 출처 데이터 확인 경로만 전환합니다. 기본 진입 화면은 홈이며 브라우저 저장소도 기존 운영 키를 사용합니다.

승인된 공개 스냅샷과 표지/로고/배지 원본 바이트를 만료되는 Actions 산출물에만 의존하지 않도록 `albums/release-seed`에 보존했습니다. 스냅샷 SHA-256은 `382f649ae240dd0d8df16121538c877ecce1dfa0505832b624853a04ce45d7a3`입니다. 기록 시각은 원래 확인 시각을 유지합니다. 이번 승격은 검토한 데이터를 그대로 적용하며 새 정기 차트 수집을 활성화하지 않습니다. 기존 수집 코드를 사용한 갱신은 `prepare_album_release.py --refresh`로 별도 실행할 수 있습니다.

`build_albums_host.py`를 사용하여 기존 1차/2차/앨범 관리자 전용 검토 경로도 계속 처리합니다. 운영 자료의 접근 정책은 기존 Gateway의 동일 출처 정적 파일 정책을 그대로 사용합니다.

## 검증 및 복구
기존 전체 CI/인증 검사에 추가하여 19곡의 7개 기록, 그래프·표지·플랫폼, 반응형 레이아웃, 홈/운영 경로, 전체 영상 보존을 최종 배포 번들에서 검사합니다. 배포는 기존 main 전용 환경·일시정지·SFTP 범위 제한·자동 복구를 사용합니다.

승격 전 소스 백업: `backup/albums-before-promotion`. 기존 운영 릴리스는 배포 도구가 저장하는 이전 라우터·게이트웨이 백업으로 복구할 수 있습니다. 사용자 승인 없이 기존 브랜치 삭제 또는 강제 푸시는 하지 않습니다.
