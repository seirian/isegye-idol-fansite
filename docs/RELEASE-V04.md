# v0.4 운영 승격

사용자가 2026-10-24에 feature/live의 현재 구현을 develop → main 순서로 배포하도록 승인했습니다. 콘텐츠 검토 기준 커밋은 a2c8993a2e20b25c689f61b64dcabda0a0866d26입니다.

## 포함 범위

LIVE와 홈 방송 현황(30초 조회/오류와 종료 구분/썸네일), 멤버 소개 6명과 21개 채널, 음악 154개와 검토한 영상 151개(공식/팬 업로드/반주 구분), 활동 연혁 55개, 7개 메뉴를 운영 빌드에 포함합니다. 지니 프로필과 사용자 제공 단체 이미지·가독성·간결한 소개를 유지합니다. 자동 새 검색이나 새로운 콘텐츠 수집 범위를 추가하지 않습니다. 영상 목록은 빌드 시 갱신하며 영상 연결은 검토된 스냅샷입니다.

## 빌드와 검사

npm run build는 build_release_v04.py를 사용합니다. 내부적으로 기존 무배포 LIVE 컴파일러를 실행한 다음 승인된 결과만 dist로 패키징하므로 재귀 호출 없이 동일 화면을 승격합니다. 기존 v0.3 빌더는 하위 템플릿과 과거 단위검사를 위해 보존합니다.

production은 refs/heads/main에서만 생성하며 index,follow·운영 대표 주소·공개 베타 표시를 적용합니다. review.html 및 저장소 소스는 운영에 업로드하지 않습니다. 개발판은 noindex를 유지합니다.

검사: 기존 단위·고정경로·원상복구 검사, 151개 선택 영상의 공개 메타데이터/업로더/썸네일 검사, 검색/즐겨찾기/달력/제보 작성 화면, LIVE/멤버/음악/연혁/썸네일/단체이미지/메타데이터 검사. 삭제한 메뉴와 옛 음반6개를 전제로 하던 기대값은 현재7개메뉴/154개기록으로 갱신합니다. 실제 외부 응답과 합성 상태전환 검사는 구분합니다. 동영상 전체 재생이나 제3자 이용허락을 검증했다는 뜻은 아닙니다.

## 순차 배포와 보호

feature/live PR → develop 검증 및 Pages 게시 → develop PR → main → 인아워넷 배포 및 실제 URL 검사. 운영 검사를 같은 트랜잭션 안에서 수행해 실패 시 이전 이세돌 라우터로 복구합니다. 공용 /web/.htaccess·미르 파일·DNS·인증서·Secret을 변경하지 않습니다. 원격 쓰기는 /web/_isegye_idol 안에만 허용합니다.

backup/main1st(885e818063eeccedf468d52ce148a4760819c97d)는 그대로 보존합니다. 이전 운영 커밋은 b422a1653fef48bf2eb91663a99c767279bb48d1이며 서버의 이전 릴리스/비공개 라우터 백업도 유지합니다.

Pages 게시에는 루트와 previews/feature-live 및 기존 second/previews/feature-readability를 포함합니다. 모든 임의 브랜치를 영구 보존하는 자동화는 아닙니다. 최종 완료는 실제 배포 보고서로 판단합니다.
