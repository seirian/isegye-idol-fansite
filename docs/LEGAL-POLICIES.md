# 이용약관·개인정보처리방침 전문 (2026-10-27, v1.0)

## 요청과 참고 범위

운영자가 지정한 https://viichan.kr/settings 의 이용약관과 개인정보처리방침을 2026-10-27에 비로그인 브라우저로 직접 확인했습니다.

- https://viichan.kr/settings/terms-of-service
- https://viichan.kr/settings/privacy-policy
- 참고 사이트의 문서 제목, 운영자/연락처/공고·시행일, 조문별 본문, 목적·항목·보유기간 표, 부칙·변경 이력이라는 문서 구성을 참고했습니다. 본문은 이 사이트의 실제 기능에 맞춰 새로 작성했습니다. 타 사이트 문구·연락처·수집내역·법률상 지위를 복제하지 않습니다.
- 참고 원문과 당시 DOM/수집 결과는 읽기 전용 Actions 40436778959의 단기 검토 아티팩트에만 있으며 서비스 패키지에는 넣지 않습니다. 장식 잠금화면이 스크린샷에 보이는 경우에도 실제 article DOM 전체를 읽어 확인했습니다.

## 적용

- auth/terms.html: 이용약관 16개 조항과 부칙·변경 이력
- auth/privacy.html: 개인정보처리방침 13개 조항, 처리내역·쿠키·호스팅·외부연동 표와 변경 이력
- /auth/terms 및 /auth/privacy는 GET/HEAD로 모든 이용자가 읽을 수 있습니다. 로그인 세션을 만들거나 계정 원장을 조회하지 않습니다. POST는405입니다.
- /terms, /privacy, /settings/terms-of-service, /settings/privacy-policy는 정식 경로로308 이동합니다.
- 로그인 화면에서 Google 버튼 전에 약관·방침 및 가입 대상 안내를 제공합니다. 별도의 가입 양식·체크박스·추가 개인정보 필드는 만들지 않습니다. 기존 회원에게 동의를 소급하여 기록하지 않습니다.
- 로그인/계정/앱 푸터에서 두 전문으로 연결합니다. 공사중 화면에는 두 문서 링크를 표시하지 않으며 기존 배경·문구·로그인 진입을 유지합니다. 예전 #/privacy는 브라우저 저장정보 삭제 기능을 유지하면서 새 방침 전문으로 연결합니다. 계정을 수집하지 않는다는 오래된 문구는 제거합니다.
- 공사중 상태·관리자 바인딩·회원 원장·식별키·JWT 검증·접근제어는 변경하지 않습니다. 조사 당시 실제 익명 상태는 maintenance=true였습니다.

## 실제 구현과 문서의 대응

회원 원장은 Google sub의 사이트 전용 HMAC 식별값과 권한만 보관합니다. 관리자 바인딩·스키마 정보는 기존 상태로 유지합니다. Google이 전송할 수 있는 이메일/이름/사진과 토큰은 인증 과정의 일시 처리이며 원장에 저장하지 않습니다. 세션에는 기존에 구현한 최소 시각/CSRF/nonce가 존재하므로 원장과 구분해 명시합니다.

Session.php의 최대12시간/비활동30분/nonce10분은 인증 유효기간입니다. PHP 세션 정리는 확률적 GC이므로 같은 시각에 모든 파일이 물리적으로 삭제된다고 쓰지 않습니다. 즐겨찾기·테마는 로컬 저장이며 로그아웃·탈퇴와 별개입니다.

직접 사용하지 않는 Firebase/GA4/Neon/Vercel/FCM/굿즈/팬카드/유료결제 처리내역을 타 사이트에서 가져오지 않습니다. 현재 Google Identity Services, YouTube 썸네일, SOOP 조회, Gmail 문의와 이용자가 직접 제출하는 GitHub 이슈를 구분합니다. 회원 원장을 해외 DB에 저장한다고 주장하지 않으며 해외 사업자 직접 통신의 가능성을 별도로 안내합니다.

## 운영자 확인이 필요한 사항

- 인아워넷의 실제 접속·보안 로그 보유기간, 백업 삭제 주기, 서버 처리 위치 및 위탁 약정은 코드만으로 확인할 수 없습니다. 공개 제공자 홈페이지 조회도403이었습니다. 이를 1일/30일/국내 전용 등으로 임의 확정하지 않았으며 본문에도 확인 범위를 구분했습니다. 운영자가 계약/설정에서 확인 후 구체적인 보유·파기 기준을 확정해야 합니다.
- 연락처는 운영자가 제공한 seirian@gmail.com을 사용합니다. 별도 문의/개인정보 전용 메일함은 생성하지 않았습니다. 문의 메일에 개인정보가 들어오면 최소 수집·목적 달성 후 삭제 절차를 실제로 수행해야 합니다.
- 회원 열람/삭제/탈퇴는 이메일 요청 및 최소 본인 확인을 통한 운영 처리입니다. 자동 탈퇴 기능을 새로 구현한 것이 아니며, 이메일만으로 HMAC 원장을 역조회하거나 신분증 전체 사본/토큰을 요구하지 않습니다. 관리자 관련 요청 시 사이트를 다시 공개하는 복구를 하면 안 됩니다.
- 만14세 이상 가입 안내는 정책 고지이며 별도의 생년월일 수집·연령 확인/법정대리인 동의 기능을 구현한 것이 아닙니다.
- 본 작업은 변호사의 법률 검토나 개인정보 보호법의 모든 요건 충족을 인증하는 것이 아닙니다. 실제 계약·처리 관행과 변경 사항을 운영자가 계속 확인해야 합니다.

## 2026-10-27 표시 간소화

운영자 요청에 따라 공사중 화면의 약관·방침 링크를 제거하고, 사이트 하단 오른쪽에는 이용약관과 개인정보처리방침만 남깁니다. 팬 가이드의 사이트 소개·운영 원칙·권리/정정 경로는 유지합니다. 전문 우측 상단의 로그인·계정 링크는 제거하고, 운영자 명칭은 “운영자”로 통일하되 문의 이메일은 보존합니다. 문서의 공사중 열람 안내만 실제 동선에 맞추며 처리 목적·항목·보유기간·권리와 인증/회원 로직은 바꾸지 않습니다.
