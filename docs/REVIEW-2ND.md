# 2차 검토 — feature/review-2nd

사용자의 1차 피드백만 반영한 별도 검토본. 운영 main/develop과 1차 검토본은 유지한다.

- 홈 최근 콘텐츠, 음악, 활동 기록의 필터·목록 구조는 1차 수용본을 유지.
- 홈 LIVE 및 LIVE 페이지는 운영 번들의 실제 렌더러·컨트롤·조회 주기·상태 규칙·스타일을 범위 제한해 재사용. 복제한 다른 LIVE 시안을 사용하지 않음.
- 주 메뉴를 LIVE / 콘텐츠로 분리. 콘텐츠는 최근 영상·다시보기·시리즈·합방 3개 탭만 제공. 이전 검토의 live?tab= 링크는 콘텐츠로 연결.
- 멤버 목록과 상세는 운영 렌더러·프로필·채널별 영상·참여 음악 사용. 1차 탭형 멤버 페이지는 제거. 저장 동작만 검토용 저장소로 연결.
- 활동 문구: OUR STORY / SINCE 2021 / 차곡차곡, 우리의 발자취. / 오디션의 첫 시작부터 음악과 무대, 함께 만든 순간까지.
- 소식·일정은 1차 월간·목록·필터·상세를 유지. 달력·목록에 멤버 색상과 이름, 소속사 별표 배지·우선 표시·전용 필터를 제공.
- 자체 저장소 네임스페이스는 review2. 1차/운영 저장소와 계정은 변경하지 않음.

## 빌드·검사

`scripts/build_review_2nd.py --baseline <verified-baseline/dist>`
`REVIEW_URL=http://127.0.0.1:4198/review.html python tests/review_2nd_browser.py`

원 운영 코드 기준 b05d0c9, 1차 검토 기준 013998a. 공지·일정 기준은 원본 1차 관측 시각을 보존하고 제작 시각으로 바꾸지 않는다.

## 별도 온라인 게시

`/review-2nd/`는 기존 관리자 인증을 통과한 후에만 읽기 전용으로 제공한다. 기존 `/review-1st/`의 핸들러·활성 포인터·HTML과 운영 UI를 보존한다. 계정 저장소·공유 라우터·수집 배치는 변경하지 않는다. 게시 실패 시 이전 엔트리·포인터로 복구한다.
