# 현재 검토본 운영 승격 (v0.3)

사용자가 현재까지의 검토본을 develop과 main에 반영하고 배포하도록 승인했습니다.

반영 범위: 단체 일러스트 히어로, 지니뮤직 프로필 6장, 14/16px 이상 가독성·대비 개선, 모바일 카드 2열, 간소화한 소개.

`npm run build`는 지니 원본 체크섬 검증 → 기존 검토 화면 컴파일 → dist 패키징 순서로 동작합니다. 기존 검토 빌더는 noindex 전용으로 유지하고, 승인된 배포 진입점인 build_selected.py만 운영 메타데이터·공개 베타 문구를 적용합니다. 운영 빌드는 Actions main에서만 가능하며 서버 쓰기는 기존 production 환경 작업에만 있습니다.

CI는 자격 증명 없이 preview와 production 패키지를 모두 빌드하고 공통 기능 및 가독성·프로필·단체 이미지 검사를 수행합니다. 실제 배포는 main 병합 후 기존 `/web/_isegye_idol` 안에서만 이루어지며 실서버 검증 실패 시 기존 원복 절차를 적용합니다. 공유 라우터와 미르 사이트는 변경하지 않습니다.

원본 첫 main은 backup/main1st (885e818063eeccedf468d52ce148a4760819c97d)에 그대로 보존합니다. 이번 변경 전 운영 커밋은 d0135773576526583ac6546f8d7f141f600c0296입니다. 이미지 출처 확인과 운영자 승인은 별도 권리자의 이용허락 취득을 의미하지 않습니다.

개발 Pages는 루트, /second/, /previews/feature-readability/를 함께 게시하여 검토 주소를 유지합니다. 임의의 모든 feature 경로 보존 기능은 아닙니다. 최종 완료 여부는 배포 보고서 status=deployed_and_verified 및 실제 URL 검사로 확인합니다.
