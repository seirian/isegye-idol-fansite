# 소식·일정 사용성 개선 (2026-10-30)

## 요청 범위
날짜 선택 시 현재 화면 위치와 키보드 초점을 유지한다. 같은 원문·같은 날짜의 중복 항목은 합치며 휴방 안내는 공지 게시에 포함한다. 최근 소식 패널은 제거하고 달력은 전체 폭으로, 선택일 상세는 아래에 배치한다. 날짜당 네 항목까지 기본 노출하며 여섯 멤버의 색상과 이름을 함께 표시한다.

## 구현 경계
- 날짜만 바뀌면 달력 DOM을 다시 만들지 않고 선택 표시와 상세 영역만 갱신한다. 다른 달·필터·피드 갱신도 스크롤과 가능한 초점을 보존한다. 다른 메뉴로 이동하는 기존 동작은 유지한다.
- 정리된 달력은 표시용 모델이다. 7,249건 공지 원본, 수집·작성자 허용목록, 서버 데이터, 회원정보에는 쓰지 않는다.
- 같은 원문의 같은 날짜는 공지를 우선하고 일정 정보를 공지 상세에 포함한다. 휴방은 별도 분류/카드 없이 원문 공지에 포함한다. 실제 방송·행사 날짜가 게시일과 다른 경우는 실제 날짜를 보존한다.
- 패러블 공식 소식은 별도 최근 소식 패널 대신 확인된 게시일의 공지로 보여준다. 날짜를 모르는 소식에 임의 날짜를 만들지 않는다.
- 아이네 보라, 징버거 노랑, 릴파 남색, 주르르 분홍, 고세구 하늘색, 비챤 초록. 단체·공통은 중립색. 선택일에도 색상을 유지하고 이름을 병기한다.
- 작은 화면은 글자를 줄이거나 네 항목을 숨기는 대신 달력 안에서 가로로 이동한다. 페이지 전체의 가로 넘침을 만들지 않는다.
