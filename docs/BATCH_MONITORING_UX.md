# 배치 모니터링 접근 안내·가독성·테마

2026-11-17 사용자 요청에 따른 보완이다. 기존 조회 전용 수집, 일정, 복구 로직, 계정 권한은 변경하지 않는다.

## 접근 안내

비관리자가 GET/HEAD로 `/ops/batches` 또는 `/ops/batches/`를 요청하면 303으로 고정 경로 `/auth/login?notice=batch-admin`으로 이동한다. 로그인 화면에 **관리자 계정만 해당 사이트에 접근이 가능합니다.** 안내를 계속 표시한다. 시간 제한 안내나 외부로 이동하는 `next` 매개변수를 사용하지 않는다.

기존 `View`의 로그인/계정 카드, 스타일, 배경, 약관/개인정보 링크를 재사용한다. 로그인된 일반 회원은 안내를 읽고 CSRF가 검증되는 명시적 POST 로그아웃 버튼으로 계정을 전환한다. GET 방문만으로 로그아웃되지 않는다. 이 경로에서 관리자 계정으로 로그인하면 서버가 권한을 다시 확인한 뒤 모니터링으로 복귀한다. 일반 로그인 동작은 그대로다.

관리자 허용 조건은 기존 세션의 `role=admin` AND `allowed=true`이다. JSON/CSS/JS는 비로그인 401, 일반 회원 403이며 로그인 HTML로 리다이렉트하지 않는다. 문서의 303은 화면 데이터 접근 허용을 의미하지 않는다. 기존 운영 문서의 문서 접근 401/403 설명은 이 문서의 안내 이동으로 대체되고, 보호 리소스의 401/403은 유지된다. 모든 접근 응답은 no-store이다.

화면에서 상태를 재조회하다 401/403을 받으면 이전 운영 자료를 화면에서 제거하고 고정 로그인 안내로 이동한다. 네트워크 오류의 과거 자료 참고 표시와 권한 상실 처리를 구분한다.

## 가독성 및 테마

홈의 글꼴, 제목 간격, 따뜻한 배경, 베리색 강조와 라운드 카드를 참고한다. 기본 글자는 16px, 표는 14px, 상태 배지는 13px이며 보조 문구도 기존 10px보다 확대한다. 데스크톱은 표, 좁은 화면은 라벨이 있는 카드형으로 표시한다. 색상만으로 상태를 전달하지 않는다.

라이트/다크/시스템 설정을 선택할 수 있다. 초기값은 시스템 설정이며 OS 테마 변경을 반영한다. `isegye:monitor-theme:v1`에 테마 문자열만 저장한다. 운영 자료, 계정, 세션, 토큰은 저장하지 않는다. 저장소가 차단되어도 테마와 모니터링이 동작한다. 본문·표·배지·관측표·상세 창 모두 테마 변수를 사용한다.

## 검증과 배포

`tests/batch_monitor_host_browser.py`는 기존 격리 TLS 인증 검사와 `tests/batch_monitor_ux_checks.py`를 함께 실행한다. 고정 리다이렉트, 일반회원/관리자 로그인, 계정 전환 CSRF, 보호 리소스 차단, PC/모바일, 테마 유지 및 시스템 변경을 검사한다. 테스트 계정은 합성 계정이다.

`batch_monitor_storage.verify_anonymous`는 쿠키 없이 리다이렉트를 따라가지 않고 303/고정 Location/한국어 안내/no-store, 보호 리소스 401, 로그인 안내 렌더링을 대조한다. 설치와 정기 상태 갱신 모두 같은 검사를 사용한다.

배포 완료 여부는 실제 실행 결과로 판정한다. 기존 공통 쓰기 잠금과 실패 시 복구 절차를 우회하지 않는다.
