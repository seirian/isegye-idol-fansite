# 소식·일정: 지정 작성자 공지와 게시 기록 (2026-10-30)

## 공개 대상 — 실패 시 비공개
사용자는 일반 이용자의 검색글을 원하지 않는다. 여섯 멤버와 소속사가 작성한 것으로 확인된 공지, 지정한 뱅온 글만 표시한다. 제목에 멤버 이름이 있거나 왁물원 URL이라는 이유로 허용하지 않는다.
- 멤버 공지: 카페 27842958 / 게시판 345 / 공개 글 / 확인된 여섯 멤버 작성자와 스탭 권한.
- 소속사 공지: 같은 카페 / 게시판 1250 / 공개 글 / parable 작성자와 매니저·스탭 권한. 이세돌 관련 내용만.
- 팬 참고: 사용자가 직접 지정한 22137397 원문만. 다른 팬 글은 추가 확인 전 비노출.
- 패러블 공식 뉴스룸: 기존 공식 사이트의 이세돌 관련 소식.

NAVER API HUB 검색은 작성자·게시판·항목별 정확한 게시일을 제공하지 않는다. API 연결 성공은 공식 작성자 확인이 아니다. 일반 검색 결과를 방문자에게 공개하던 경로는 중단했다. 기존 키·이관 코드·안전한 목적지 검사는 유지하지만, 정기 수집에서는 불필요한 검색 호출을 하지 않는다. 추후 허용된 작성자 검증 경로가 확보돼도 검증 전에 공개해서는 안 된다.

`notice_policy`는 검증된 원문 URL과 출처 분류를 대조한다. 네이버 검색 항목은 과거에 저장된 것도 제거한다. 수집 실패 시에도 제외 글을 보존하지 않는다. 발행기는 현재 JSON과 직전 복구 JSON을 모두 정리한다. 프런트도 동일 원문 허용목록을 검사하여 오래된 API 결과를 받더라도 일반 이용자 글을 표시하지 않는다. 사용자 지적 원문 22133027 / 22133865는 명시적 제외 회귀 검사에 포함한다.

## 2021-08-26 이후 공지 기록
사용자의 전체 과거 조회 요청으로 지정 게시판의 **공개 목록**을 비로그인 브라우저에서 일회성 확인한다. 게시판·작성자·권한·공개 여부를 대조한다. 일반 사용자, 다른 게시판의 고정 공지, 지정하지 않은 작성자, 비공개 글은 배제한다. 차단·로그인 요구·CAPTCHA가 나오면 중단하며 우회하지 않는다. 이 작업은 정기 카페 본문 크롤러가 아니다.

공개 목록의 제목·작성자 범주·원문 ID·게시일·검증 범위만 `schedule/approved-notices.json`에 보관한다. 원문 계정ID/memberKey, 댓글, 본문 전문, 쿠키, 로그인 정보는 저장하지 않는다. 의료 등 개인적 사유가 제목에 직접 쓰여 있으면 중립적인 공지 제목으로 바꾸고 세부 내용은 원문에서 확인하게 한다.

`notice-history-coverage.json`에 실제 읽은 페이지/건수/누락/시작·끝을 기록한다. 모든 페이지 확인과 모든 본문 내용의 해석 완료는 다르다. 공개 목록 끝까지 읽은 경우에만 complete=true이며, 본문 전문 검토를 완료했다고 표시하지 않는다. 삭제·이전·비공개 글까지 포함한 '존재했던 모든 글'의 완전성은 보장하지 않는다.

과거 공지는 빌드에 별도로 포함되어 정기 피드의 최근600개 한도로 잘리지 않는다. 달력에는 **공지 게시일 기준 '공지 게시'**로 표시한다. 공지를 쓴 날을 방송 예정일로 바꾸지 않는다. 제목에서 날짜가 명확히 확인되는 글만 별도 방송·휴방·행사 일정으로 추출한다. 시간 미표시·오전오후 불명·다중 날짜·이미지 전용 일정은 임의 확정하지 않는다. 연월 선택과 첫 공지 이동으로 과거 기록을 탐색한다.

## 자동 갱신·저장과 보호
패러블 뉴스룸/RSS는 매 실행 robots 허용 범위를 확인하고 수집한다. 카페 및 내부 API robots의 Disallow 규칙에 따라 **예약 작업에서 카페 본문/목록 반복 크롤링은 하지 않는다**. 초기 지정 뱅온 자료와 공지 기록의 확인일을 예약 실행일로 덮어쓰지 않는다. 새 멤버 공지는 작성자 대조 전 공개하지 않는다.

기존 main 매시간17분 및 운영 배포 성공 후의 데이터 갱신을 유지한다. GitHub 실행은 지연될 수 있다. PRODUCTION_PAUSED / ISEGYE_SCHEDULE_PAUSED=true로 중지 가능. 데이터는 /web/_isegye_idol/.schedule-feed 내 소유표식·현재/직전JSON·잠금만 원자적으로 갱신한다. 회원원장·권한·인증키·공용라우터·다른 프로젝트를 읽거나 수정하지 않는다.

/api/schedule은 기존 권한검사를 통과한 방문자만 읽는다. 페이지의5분 조회/새로고침은 저장 결과만 읽는다. 일반회원·비로그인의 공사중 제한을 유지하며, 운영 관리자 세션을 대신 생성하지 않는다.

## 자료 삭제
제외 정책을 현재·복구 스냅샷과 빌드 원본에 함께 적용한다. 권리 요청·삭제된 공지를 제거할 때에는 approved-notices와 seed도 수정하여 재삽입을 막아야 한다. 외부 원문 삭제 자동 감지를 보장하지 않는다.
