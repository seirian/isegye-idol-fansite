## 출제에 적용할 구분

- 접근 확인과 정답 사실 검증은 별개다. 글을 읽었다고 모든 답안을 검증 완료로 표시하지 않는다.
- 나무위키와 왁물원 글은 소재 탐색 및 교차 검토에 활용하고, 문제 표현과 해설은 새로 작성한다.
- 참고 글 URL, 원문 문항 번호, 정답 근거, 확인 시점을 구분해 기록한다.
- 수정된 답안은 최신 본문과 정정 댓글을 함께 확인한다. 논쟁·오류·시점 의존 항목은 보류한다.
- 최애·선호를 묻는 항목은 점수 없는 선택형 콘텐츠와 분리하고 자동 정답 처리하지 않는다.
- 날짜·음반뿐 아니라 멤버·팬문화·커버·공개 활동 소재도 출제 후보에 포함한다.

나무위키 그룹 문서는 이번 CI 브라우저에서 보안 확인 화면만 표시됐다. 해당 실행으로 나무위키 본문까지 읽었다고 주장하지 않는다.
