# ISEGYE! — 두 번째 팬사이트 시안

브랜치: `feature/second`. 기준: 운영 개설 커밋 `885e818063eeccedf468d52ce148a4760819c97d`.

## 컨셉

관리형 정보 포털 대신 아이돌 팬클럽의 포토카드·앨범·팬레터 감성을 사용합니다. 코랄·라벤더·크림색 배경, 큰 한글 타이틀, 여섯 멤버 포토카드, 하트 즐겨찾기, 음악 추천 영역, 일정 메모, 네 가지 탐색 카드로 구성합니다. 모바일은 멤버 카드를 3열 2행으로 보여주며, 밝은/어두운 테마와 모션 최소화 설정을 지원합니다.

8개 메뉴, 검수된 기존 데이터, 한글 초성 검색, 멤버→음악 연결, 상세 페이지, 달력, 즐겨찾기, 공개 GitHub 제보 작성 흐름은 유지합니다. 자동 LIVE·가짜 일정·인기 지표·유료 기능은 넣지 않습니다.

## 이미지 요구사항 — 아직 미완료

요청한 나무위키 멤버별 프로필 원본은 확보하지 못했습니다. 나무위키는 HTTP 403, 공개 미러의 이미지 서버는 HTTP 503을 반환했습니다. 미러 문서의 파일명은 기록했지만 현재 원문 이미지와 동일하다고 검증하지 않았습니다.

현재 시안은 **패러블 공식 소개 페이지의 여섯 프로필을 명시적으로 표시한 임시 대체본**을 사용합니다. 원본 URL과 SHA-256, 확인일, 요청한 나무위키 파일명은 `second/portraits.json`에 있습니다. 나무위키 이미지를 사용했다고 주장하지 않으며, 홈과 각 멤버의 출처 영역 및 사이트 소개에서 이 차이를 알립니다. 원본 이미지 업로드 또는 접근 가능한 원본 파일이 제공되면 교체할 수 있습니다.

공개 이미지의 존재는 재사용 허락을 뜻하지 않습니다. 권리는 각 권리자에게 있으며, 새로운 사이트 전체의 공식 승인도 받았다고 표시하지 않습니다. 이미지 요청 충족·권리 확인 전 운영 반영하지 않습니다. 회원·결제·모금·이미지 다운로드 자료실은 없습니다.

## 실행

Node 22+, Python 3.10+ 및 Pillow 11.3.0:

```sh
python -m pip install pillow==11.3.0
npm test
python scripts/build_second.py
python -m http.server 4174 --bind 127.0.0.1 --directory second-dist
```

`second-dist/index.html`은 웹서버용, `second-dist/review-second.html`은 외부 자산 요청이 없는 단일 파일 검토본입니다. 다운로드한 검토 패키지의 6개 검증된 WebP를 `--asset-dir`로 지정하면 네트워크 없이도 빌드할 수 있습니다.

`second/compose.py`는 원본 `src/app.js`의 데이터·컨트롤러를 유지하고 화면 템플릿만 합성합니다. 공유 코드가 바뀌어 기준 함수가 일치하지 않으면 빌드를 중단합니다. `second/theme.css`는 독립 스타일입니다. 기존 root 앱/빌드/운영 배포 코드는 덮어쓰지 않습니다.

## 검증과 배포 경계

`Second concept - isolated review`에서 기존 Node 검사, 실제 브라우저 기능 9개 및 추가 이미지·390/320/768/1440px·오프라인 검사를 실행합니다. 성공한 경우 기존 develop 미리보기 빌드를 루트에 보존하면서 `/second/`에 새 시안을 추가한 Pages 패키지를 배포합니다. GitHub 환경의 기존 허용 규칙을 변경하거나 우회하지 않습니다. 환경 정책으로 feature 배포가 막히면 검토 HTML 아티팩트를 사용합니다.

이 작업은 `main`, `develop` 브랜치 쓰기, 인아워넷/SFTP 접근, 운영 Secret 사용, 공유 라우팅 변경, 미르 프로젝트 변경을 하지 않습니다. Pages의 기존 루트 파일은 develop에서 다시 빌드해 보존합니다. 이후 기존 develop workflow가 Pages 전체를 새로 게시하면 `/second/`는 없어질 수 있으므로, 장기 보존은 feature 검토 workflow 재실행 또는 정식 검토 후 통합 계획이 필요합니다.

`DEPLOY_ENV=production`으로 두 번째 시안을 빌드하려 하면 명시적으로 중단합니다. 이 브랜치의 구현을 main에 자동 병합하지 않습니다.
