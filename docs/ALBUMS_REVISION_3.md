# 앨범 검토판 — 두 번째 피드백

브랜치 `feature/albums`, 관리자 검토 `/review-albums/` 전용. main 병합, 운영 음악 화면 변경, 운영 일/월배치 수정 없음.

## 반영

- 보이는 명칭을 앨범으로 통일. 기존 제목 `한 곡에서 시작되는 이야기` 유지.
- Spotify/FLO 링크, 로고, 연결 상태와 수집/인증값 참조 제거. 과거 feature 캐시에 있던 항목도 출력하지 않음.
- 멜론 → 지니·벅스·유튜브 뮤직·유튜브 → 애플 뮤직 순서. 음원 연결·상태·차트 선택·메타데이터의 필드별 fallback에 적용. 동종 지표만 대체하며 MV 길이를 음원 길이로 사용하지 않음.
- 카드/리스트 전환 옆 초기화 삭제. 기존 정보 범위 삭제 유지.
- 공식 Melon `millions.htm`의 앨범 ID·제목·아티스트·달성 라벨과 배지 클래스를 대조. 공식 3x sprite의 정해진 배지 영역만 무손실 추출하고 공식처럼 수치 라벨을 겹쳐 표시. 새 배지 디자인이나 임의의 달성 등급을 만들지 않음.
- 카드/리스트의 앨범 제목 우측, 앨범/곡 상세 제목 우측에 배지. 곡 상세의 배지도 **소속 앨범 발매 첫 24시간 기록**이며 곡 단독 누적 재생수로 주장하지 않음.
- 상세 상단에 멜론 TOP100 / HOT100(100일) / 실시간 최고 성적 3칸. 앨범 상세에서는 선택한 수록곡 기준.

## 출처와 정확성

명예의전당은 멜론 공식 공개 목록과 이미지가 출처. 해당 목록에 없는 앨범은 배지를 표시하지 않는다. 같은 앨범 ID의 수록곡끼리만 같은 배지를 공유한다. 원본 이미지/CSS의 사용 허락이 별도로 확인됐다고 주장하지 않는다.

최고 성적은 멜론 공식 공개 곡 페이지에서 해당 3종 이력을 제공하는 경로를 확인하지 못해 **이세계차트의 공개 관측 기록**을 별도로 명시하여 연결한다. 매번 정확한 멜론 곡 ID·앨범 ID·곡명·가수를 대조한다. 참고 사이트 UI·가사·추이 데이터를 복제하지 않는다. 목록을 통해 확인한 19개 곡 페이지 ID만 요청하며, 파싱 실패를 기록 없음/0위로 바꾸지 않는다.

최고 성적은 수집자의 관측 범위에 의존하며 멜론이 보증하는 전기간 최고 기록이 아니다. 화면에 출처·확인 시각·미확인 상태를 제공한다. 최근 24h/7d/30d 그래프의 관측 최고는 이 기록과 별개다. 과거 순위를 임의로 보간하지 않는다.

공식 음원 재생시간을 확보하지 못한 경우 애플 뮤직 US 메타데이터가 마지막 대체 출처다. 유튜브 뮤직은 검색 연결이며 유튜브 영상 조회수를 뮤직의 음원 재생수로 표기하지 않는다.

## 운영 경계

동일 출처 관리자 전용 API, noindex/no-store, 기존 인증 보호와 파일 해시 검증 유지. 현재 feature push/수동 실행만 갱신하며 정기 수집은 활성화하지 않음. 검토 승인 전 운영 전환 금지.
