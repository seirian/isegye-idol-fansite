# 1차 검토 온라인 접속

검토 URL: `https://isegye-idol.kr/review-1st/`. 기존 Google 로그인으로 등록된 관리자만 접근한다. `/auth/login`에서 로그인한 뒤 검토 주소를 다시 연다. 새로운 계정·권한·세션 우회 경로는 없다.

UI 소스와 커밋은 `feature/review-1st`에만 있다. main/develop 병합이나 운영 UI 교체를 하지 않는다. 기존 홈 주소, 일정·음악·활동 수집, 로그인·개인정보 문서는 유지한다.

검토 전용 빌드는 배포 자격 증명 없이 실행한다. 성공한 결과만 별도의 재사용 워크플로가 기존 production 환경 승인·중지 설정·공유 배포 동시 실행 잠금 아래 게시한다.

## 서버 변경 범위

- `.review-1st` 비공개 폴더: 불변 HTML·검토 메타데이터와 체크섬, 원자적 활성 포인터, 이전 값 백업.
- `.auth-runtime`의 새 불변 런타임: 기존 파일을 재사용하고, 기존 접근 제어 이후 검토 경로만 처리하는 생성 코드를 추가.
- 관리되는 `access.php` 진입점: 새 런타임을 참조하도록 원자적으로 교체. 기존 템플릿과 이전 값 일치 확인 후만 변경.
- 루트 `.htaccess`, 실제 운영 릴리스 파일, 계정·설정·세션 저장소, 다른 사이트 파일은 변경하지 않는다. 배포기는 계정 파일·비밀 설정을 읽지 않는다.

인증된 관리자의 미리보기는 원래 해시 CSP가 유지된 정확한 검토 HTML이다. 익명·일반 회원, 비공개 파일 직접 주소, 변조·심볼릭 링크는 거부한다. 서버 게시 후 바이트 읽기, 익명 차단, 기존 페이지 응답 및 운영 릴리스 보존을 검증한다. 실패 시 자신이 변경한 진입점과 포인터만 이전 값으로 복구한다.

화면·로그인 경로 검사는 로컬 TLS 서버와 명시적인 합성 Google 서명 토큰을 사용한다. 실제 Google 계정 로그인을 대신 수행하지 않는다. 운영 검증의 범위는 게시 파일 바이트와 접근 제한, 기존 응답 보존이다.

## 검토 수명

이 경로는 독립 검토용이다. 향후 main의 정상 운영 배포는 원래 인증 런타임을 다시 적용할 수 있다. 그 경우 feature/review-1st 워크플로를 다시 실행해 검토 경로를 재게시한다. 본 검토를 장기 운영 기능으로 만들려면 별도 승인된 변경으로 호스팅 연결을 main에 통합해야 한다.

기준 빌드·이미지는 검증된 GitHub 아티팩트에 고정한다. 보존 기간 만료 후에는 별도로 검증한 새 기준 빌드를 지정해야 하며 무검증 최신 자료로 자동 대체하지 않는다. 알림 서버·계정 동기화·일반 영상 신규 배치는 여전히 연결 전인 검토 시안이다.
