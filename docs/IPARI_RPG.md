# 이파리 연대기: 마지막 앙코르

2026-11-18 사용자가 승인한 기획을 구현하는 독립형 팬 RPG 검토본이다. 플레이어는 이파리이며, 2021~2026년의 활동 기록을 모티프로 삼은 여섯 지역에서 멤버를 만나고 마지막에 우왁굳의 친선 시험에 도전한다.

**2026-11-18 사용자가 develop·main 반영과 운영 배포를 승인했다.** 운영에서는 놀이터 카드에서 `/games/ipari-chronicle/`로 이동하며 하단 링크로 돌아온다. 기존 관리자 접근 정책을 유지한다. `rpg-dist/`는 별도의 로컬 검토 산출물이며 이 문서나 빌드 성공만으로 운영 게시 완료를 의미하지 않는다.

운영 합성은 `scripts/build_rpg_production.py`와 `promote_playground.py`가 담당한다. `rpgGame` 메타데이터에 소스·게임·카드 그림의 체크섬을 기록하고 배포기는 승인 소스와 대조한 뒤 게시 바이트를 다시 읽어 검증한다. 정확한 게임 HTML 경로만 인증 게이트에 추가한다. 기존 놀이터 퀴즈, 별빛 배송부, 검토 경로, 계정·배치 정책을 유지한다. 운영 도메인과 로컬 검토 주소의 저장은 별개다.

## 게임 범위

- 6개 장, 각 3개 방과 최종 객석 1개로 총 19개 탐험 공간.
- 장마다 멤버 만남, 다른 방식의 퍼즐, 일반 전투와 보스전. 마지막은 3단계 시험관 전투다.
- 기본 행동은 공격·방어·응원·지원. 적의 다음 행동을 보고 선택한다. 멤버별 지원기술 6개와 성장 선택을 제공한다.
- 실제 기록 12개를 기록첩에서 확인한다. 선택 대화, 쉼터, 전투 재도전과 도움 기능을 포함한다.
- 결말은 이파리의 자리로 돌아가는 완결된 앙코르다. 반복 사냥, 결제, 서버 순위나 계정 연동은 없다.

첫 플레이 **40~50분**, 선택 탐험을 더해 **1시간 이내**가 설계 목표다. 이 수치는 사람의 첫 플레이를 측정한 결과가 아니다. 자동 완주·재현 테스트 시간으로 실제 독해, 탐색, 판단 시간을 주장하지 않는다. 사람의 첫 플레이에서 목표 범위를 확인하고 조정해야 한다. 빌드 메타데이터도 `playtime.humanMeasured=false`로 기록한다.

## 실행과 조작

의존 패키지 추가 없이 프로젝트 루트에서 빌드한다.

```sh
python3 scripts/build_rpg.py
python3 -m http.server 4177 --bind 127.0.0.1 --directory rpg-dist
```

Mac에서는 `rpg/게임 시작.command`를 더블클릭하면 같은 주소로 서버와 브라우저를 연다. 터미널에서는 `python3 scripts/serve_rpg.py`를 실행한다. 이미 같은 게임 서버가 실행 중이면 재사용하며, 다른 서버가 해당 포트를 쓰면 안내하고 중단한다. 임의로 포트를 바꾸거나 기존 서버를 종료하지 않는다.

브라우저에서 `http://127.0.0.1:4177/`를 연다. 검토 서버는 로컬 주소에만 바인딩한다. `index.html` 자체가 이미지·CSS·JavaScript를 포함하므로 서버의 API는 필요하지 않다. PC 재시작 뒤에도 같은 실행기를 사용하고 **이전에 플레이한 브라우저**에서 위 주소를 열어야 한다. `localhost`, `127.0.0.1`, 다른 포트, HTML 직접 실행(`file://`)은 저장 공간을 공유하지 않는다. HTML 직접 실행은 새로 플레이할 때 사용할 수 있지만 HTTP에서 만든 저장을 자동으로 이어받지 않는다.

방향키·WASD와 화면의 방향 버튼으로 이동하고, 인접한 대상과 상호작용한다. 전투와 대화는 이용자의 선택을 기다린다. 진행 기록은 브라우저 로컬 저장 키 **`isegye:rpg:v1`**, 소리·테마·움직임 설정은 **`isegye:rpg:settings:v1`**에 저장한다. 서버 계정이나 별빛 배송부·퀴즈 기록과 공유하지 않는다. 다른 기기나 다른 도메인에는 동기화되지 않는다. 브라우저가 저장을 차단하거나 저장 공간이 부족한 경우에는 이어하기를 보장할 수 없으므로 UI에서 저장 실패를 안내한다. 환경설정 JSON의 손상은 유효한 진행 저장을 버리는 이유가 되지 않는다.

## 파일과 빌드 계약

- `rpg/index.html`: `<!--CSP-->`, `<!--STYLE-->`, `<!--SCRIPT-->`가 각각 한 번 있는 문서 틀.
- `rpg/styles.css`: 별도의 원격 폰트·이미지 없이 사용하는 화면 스타일.
- `rpg/content.js`: 기록 출처, 장과 방, 대화, 퍼즐, 조우 설정.
- `rpg/engine.js`: 화면에 의존하지 않는 게임 상태와 진행·전투·저장 검증.
- `rpg/app.js`: 화면과 조작, 로컬 저장.
- `rpg/assets/{worlds,members,cast}.webp`: 이번 게임을 위한 새 이미지. 원본과 생성 프롬프트는 `rpg/art-source/`에 보존한다.
- `scripts/build_rpg.py`: 세 모듈과 CSS, WebP를 단일 HTML로 묶는다.

번들러는 위 순서로 세 모듈을 이어 하나의 `type="module"` 스크립트를 만든다. 앞에서 합친 `./content.js`, `./engine.js`에 대한 이름 있는 import만 제거한다. 별칭 import, 외부 모듈, 동적 import, default export는 지원하지 않으며 빌드가 실패한다. 세 파일의 최상위 이름은 충돌하지 않아야 한다. 원본의 named export는 그대로 남아 Node 단위 테스트에서도 사용할 수 있다.

게임에 전달되는 `RPG_ART`는 `worlds`, `members`, `cast` 키의 WebP data URI 객체이다. 그림을 CSS URL로 직접 불러오지 않는다. 필수 그림이 없거나 WebP가 아니면 빌드하지 않으며 대체 도형만으로 완료했다고 표시하지 않는다.

산출물은 `rpg-dist/index.html`, 동일한 `review.html`, `build-info.json`이다. HTML은 최대 8 MiB, 그림은 각각 4 MiB 미만이다. 매니페스트에 HTML 크기·SHA-256, 모든 소스 파일과 포함 이미지의 SHA-256, 저장 키, 원자료 확인 시점, 실제 플레이 시간 미측정 상태를 기록한다. 빌드 시간 메타데이터를 제외한 같은 소스의 HTML은 바이트 단위로 재현 가능하다.

Content Security Policy는 `default-src 'none'`, 해시로 허용한 단일 스크립트·스타일, `img-src data:`, `connect-src 'none'`를 적용한다. 게임 실행에 외부 스크립트·폰트·미디어·네트워크 요청을 허용하지 않는다. 기록첩의 출처 링크는 사용자가 누르면 원문으로 이동하는 일반 링크다. 빌더는 입력·출력 심볼릭 링크, 삽입된 종료 태그, NUL, 외부 CSS URL, 문서 틀의 인라인 이벤트를 거부한다.

패키징 검사는 격리된 임시 파일로 해시·이미지 복원, 재현성, 기존 파일 보존, 위험 입력 거부, 필수 그림 누락, 운영 브랜치 빌드 차단을 확인한다. 게임의 첫 장부터 최종 엔딩까지 진행 가능 여부, 모든 퍼즐, 지원기술, 패배·재도전, 손상 저장 복구는 엔진 검사와 브라우저 검사에서 별도로 검증한다. 실제 로그인이나 사용자 세션을 만들거나 가장하여 검사하지 않는다.

브라우저 검사는 `127.0.0.1`의 독립 서버에서 실제 빌드 파일을 연다. 지도 이동은 방향키·화면 방향 버튼, 대화·퍼즐·전투는 공개 버튼만 사용한다. 진단용 `snapshot()`은 읽기만 하며 엔진 dispatch를 직접 호출하거나 완료 저장 데이터를 주입하지 않는다. 실패 처리 검사용 저장 fixture는 손상 JSON과 저장 API 거부뿐이다.

2026-11-18 후속 보완본의 로컬 통합 검증에서 엔진 **14/14**, 패키징 **13/13**, 브라우저 **213개**를 통과했다. 브라우저는 여섯 장·모든 퍼즐·12개 사실 기록·13개 전투·3단계 최종전을 공개 조작으로 완주했다. 의도적인 패배와 재도전, 새로고침 복원, 손상된 환경설정, 저장 거부 시 현재 탭 이어하기, 키보드 방어 초점, 일시정지, 도움 모드와 테마 유지를 확인했다. 320·390·768·1440px에서 가로 넘침과 캐릭터 셀 비율을 검사했고 외부 요청·JavaScript 오류·CSP 위반은 없었다.

최종 실행 폴더: `test-results/rpg/runs/20261118T111700.037152Z-6378102f82ca-c85a68`. 각 실행은 UTC 시각·HTML 해시·고유 ID가 붙은 새 폴더를 생성하며, 검증한 HTML·빌드 메타데이터·번호가 붙은 모든 캡처·보고서를 함께 보존한다. `test-results/rpg/report.json`은 가장 최근 시도, `latest-passed.json`은 가장 최근 성공을 가리킨다. 실패한 새 실행도 과거 성공 폴더를 덮어쓰지 않는다. 최초 검토 당시 버전이 섞였던 캡처는 `test-results/rpg/legacy-first-review-mixed/`에 따로 옮겼으며 최종본 증거로 사용하지 않는다.

실행기는 기존 동일 서버 재사용을 실제 로컬 주소에서 확인했다. 별도 모의 검사에서는 다른 파일을 제공하는 서버에 대한 중단, 고정 주소 신규 바인딩, 종료 시 서버 정리를 확인했다. 새 포트나 다른 호스트명으로 자동 이동하지 않는다.

`.github/workflows/rpg-review.yml`은 `feature/ipari-rpg`에서 같은 검사 후 게임·실행별 검증 자료를 업로드하도록 구성했다. 검증한 HTML과 보관본의 동일성도 확인한다. 이번 결과는 로컬 검사이며 커밋·Actions 실행·운영 배포 완료를 뜻하지 않는다.

## 놀이터와 검토 주소 통합

기존 `/review-playground/`는 별빛 배송부 검토본을 유지한다. 현재 `PlaygroundPreview.php`는 그 경로만 허용하므로 RPG 파일만 새 폴더에 올려도 `/review-rpg/`가 자동으로 제공되지는 않는다.

독립 검토 주소가 필요하면 별도 `RPGPreview.php`와 **기존 `allowed=true` 검사 뒤에 놓인 서버 `role=admin` 경로**를 추가해야 한다. 이 작업은 기존 런타임 파일·의존성을 보존하는 불변 런타임 배포, 공통 운영 쓰기 잠금, 포인터와 진입점의 비교 후 교체·롤백, 모든 기존 검토 포인터 보존, 비관리자·직접 파일 접근 차단 검증을 포함한다. 현재 이 게임 패키징 작업은 인증 런타임·진입점·라우터를 수정하지 않는다.

운영 놀이터에 게시할 때는 기존 퀴즈와 별빛 배송부를 보존한 상태에서 새 카드와 독립 게임 경로를 추가해야 한다. 사용자 검토 전의 이번 빌더는 `main`·`develop` 및 `DEPLOY_ENV=production` 실행을 거부한다. 운영 통합·게시가 이루어지면 실제 배포 보고서, 서버 게시 파일 재조회와 해당 접근 정책 검증 결과를 이 문서에 별도로 기록한다.

### 1차 마감 기록 (2026-11-18)

마감 직전 캐릭터 표시 비율 조정에서 390px 엔딩 가로 넘침이 발견되어 해당 CSS 변경을 전부 철회했다. 193개 브라우저 검사를 통과했던 HTML SHA-256 `40c1d325255f411ae402f0959a41e79ce71d1ffb6e479fa787eff974be60d8cb`와 바이트 단위로 동일하게 재빌드한 파일을 1차 검토본으로 확정했다. 철회한 시도의 보고서는 `test-results/rpg/art-ratio-rejected-report.json`에 보존한다. 당시 스크린샷 중 일부는 철회한 시도의 캡처였다. 현재는 legacy-first-review-mixed 폴더로 분리했으며 최신 검증 자료와 구분한다.

마감 재빌드의 실제 메타데이터 시각은 15:58:27 KST였다. 이전 문서의 “15:58 이전” 표기는 부정확하여 정정했다. 당시 성공 보고서 원본은 마지막 실패 시도에 덮어써졌으며, 이후 읽기 검토에서 동일한 1차 납품 SHA를 재검증해 193개 검사를 통과했다. 원래 성공 보고서가 복구된 것으로 간주하지 않는다.

## 후속 보완과 플레이 시간 검토

- 캐릭터 atlas는 모든 표시 위치에서 정사각형 셀 비율을 유지한다. 모바일 엔딩은 4명·3명 두 줄로 표시해 가로 넘침을 방지한다.
- 18개 방에 서로 다른 지형을 사용한다. 중앙 이동 경로와 주요 대상 접근성을 유지하며, 이동 시간을 억지로 늘리지 않는다.
- 기존 저장 키와 진행을 유지한다. 최초 검토본에는 없던 `mapRevision=2`를 사용하며, 이전 저장 위치에 새 벽이 생겼다면 가장 가까운 바닥으로만 이동한다. 전투·재도전 위치·동료·기록·성장 내용은 유지한다.
- 성장 3회에서 가능한 27개 조합을 기본·도움 모드로 각각 자동 완주했다(54개 경로). 같은 방어·회복 전략에서 기본 160~209턴, 도움 106~137턴이었다. 이는 선택 조합의 진행 가능성 검사이며, 초보자의 체감 난이도나 재미를 검증한 수치가 아니다. 이 결과만으로 전투 수치를 임의로 변경하지 않았다.

사람의 첫 플레이 소요 시간은 아직 측정하지 않았다. 첫 플레이 검토는 정답표 없이 기본 모드에서 진행하고 장마다 소요 시간, 퍼즐에서 막힌 지점, 재도전 횟수, 반복적으로 느껴진 전투를 기록한다. 총 30~60분 목표를 벗어나면 실제 원인을 기준으로 대사·단서·전투 길이를 조정한다. 도움 모드는 막혔을 때 전환할 수 있게 유지한다. 자동 테스트 실행 시간에 읽기 시간을 임의로 더해 사람의 플레이 시간으로 보고하지 않는다.
