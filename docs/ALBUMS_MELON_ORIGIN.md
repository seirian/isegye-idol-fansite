# 멜론 원본 최고 순위 — feature/albums 검토판

2026-11-09 사용자 피드백: 음악 순위는 가급적 원본 제공처에서 직접 가져옵니다.
이 문서는 이전 이세계차트 최고 성적 연동 설명을 대체합니다. main 미병합, 운영 UI/기존 배치 미변경.

## 원본에서 확인한 내용

인증값·앱 클라이언트 키·로그인 없이 다음 멜론 원본 응답을 확인했습니다.

- 곡 정보: `https://m2.melon.com/m6/v5/song/info.json?songId=603093102`
- 곡 화면: `https://www.melon.com/song/detail.htm?songId=603093102`
- 확인한 곡: 고양이가 세상을 구한다!, 고세구, NO CAT, NO LIFE!
- 원본 `SONGACHIEVEMENTINFO.BESTRANK`: **527**
- `BESTRANKDATE`: **2026.09.28**
- 원본 GUIDE가 밝히는 범위: **일간 차트, 2014.01.01 이후 기록**.
- 이 값은 TOP100/HOT100/실시간 최고 순위가 아닙니다. 현재 순위 또는 어제 순위와도 다릅니다.
- 이 곡 응답의 원본 SHA-256(초기 확인): `0581ca7bfe3051cfde8ed9109bcc96220934c7ec9cdb5b4fda77da1e809fb82a`.

차트 리포트 `https://m2.melon.com/m6/chart/song/chartReport.json?songId=603093102`는
이번 확인에서 차트 갱신 안내만 반환했습니다. 현재 차트 진입 곡에 대한 같은 경로는 최근 TOP100 추이,
다음 시각 예측, 별도의 일간 최고 기록을 반환했습니다. 최근 추이나 예측값을 전기간 최고로 계산하지 않습니다.
원본에 다른 확인 경로가 절대로 없다고 결론내리지 않습니다. **이번 확인 범위에서 TOP100/HOT100/실시간의
전기간 최고 3종을 직접 확인하지 못한 상태**입니다.

## 변경한 정책

- 외부 사이트 최고 기록 수집, ID 매핑 파일과 링크 허용을 제거했습니다.
- 멜론 ID·앨범 ID·곡명·앨범·가수와 일간 범위를 대조한 원본 기록만 출력합니다.
- 상세 상단에 일간 최고와 기록일, 멜론 원본 링크, 확인 시각을 표시합니다.
- 기존 TOP100/HOT100(100일)/실시간 슬롯은 `공식 최고 기록 미확인`으로 표시합니다.
- 멜론 원본에서 직접 수집하는 최근 TOP100/HOT100 그래프는 유지하며 `기간 내 관측 최고`와 역대 최고를 구분합니다.
- 이전 캐시에 남은 이세계차트 수치를 원본 기록으로 재사용하지 않습니다. 빌드도 외부 기록이 남으면 실패합니다.
- 수집 실패 시 동일 곡의 이전 **멜론 원본**만 원래 확인 시각 그대로 유지하며 실패 사실을 표시합니다.
- 원본을 읽었더라도 공식 공개 API 계약이나 영구적인 제공 보장을 받은 것으로 표현하지 않습니다.
- 가사·청취자 분석 정보는 저장하거나 화면에 전달하지 않습니다. 음원 길이는 멜론 PLAYTIME이 확인되면 우선합니다.
