# 베리즈 공식 공지·캘린더 (2026-10-30)

## 수집 범위
사용자가 지정한 https://berriz.in/ko/isegyeidol/notice/ 와 /calendar/ 만 대상으로 한다. 커뮤니티40의 공식 공지 목록과 공식 캘린더를 비로그인 공개 브라우저로 확인한다. 다른 아티스트·팬 게시판·회원 전용 게시글·본문·댓글·이미지·팬 개인정보는 저장하지 않는다. 추가 Berriz 계정/키가 필요 없다. 사이트 회원정보를 사용하지 않는다.

공개 웹 robots.txt는 두 경로를 허용한다. 매 실행 재확인하고 오류/금지 시 중단하여 이전 자료와 확인시각을 유지한다. svc-api의 robots 요청은403이므로 직접 API 수집 경로를 만들지 않는다. 캘린더는 일반 공개 페이지가 정상 로딩하면서 받은 응답 중 현재 표시된 월의 화면에 실제 노출된 제목만 처리한다. 인증값/쿠키 주입, 프록시/접근제어 우회를 하지 않는다. 공개 응답의 draft/future-publication/다른 월 항목은 노출하지 않는다. Berriz 약관의 팬클럽 전용 콘텐츠 외부 게시 금지를 준수하며 제목/명시 날짜/원문 링크만 최소 저장한다. robots 허용이 포괄적 재이용 허가를 의미하지는 않는다.

## 날짜와 중요도
공지 목록의 게시일은 날짜 정밀도로 저장하고 공지 게시 기록에만 사용한다. 본문을 읽지 않은 발매 공지에서 임의 행사일을 만들지 않는다. 캘린더 startDate는 Asia/Seoul로 변환하며 종일 표시는 유지하고00:00 약속으로 만들지 않는다. endDate가 있는 경우 원래 기간을 상세에 보여주되 종료일 포함 여부·반복 일정을 추정해 복제하지 않는다. 캘린더 상세의 영구 개별 주소가 제공되지 않아 검증된 캘린더 메뉴 원문으로 연결한다. 멤버는 공개 표시된 이름만 내부 여섯 멤버에 대응시키며 외부 회원ID를 저장하지 않는다.

베리즈 공지는 동일 날짜의 최우선, 베리즈 공식 일정은 그 다음으로 정렬한다. 네 개 기본 노출에서도 이 순서를 유지한다. ‘★ 소속사 중요 공지’ 배지와 선을 추가하고 기존 멤버 색상은 보존한다. 출처 필터에 ‘베리즈 공식만’을 추가한다. 최근 소식 패널은 복구하지 않는다. 동일 캘린더 ID는 한 건이며 같은 날짜에 원문 메뉴URL이 같더라도 다른 이벤트ID는 합치지 않는다. 기존 같은 원문/같은 날짜 공지 통합과 휴방 통합은 유지한다.

## 갱신/실패 처리
기존 매시17분/성공한 운영 배포 이후 수집에 포함한다(실제 실행 지연 가능). 브라우저 한 세션으로 공지 목록을 최대8회 스크롤, 캘린더는 지난달·현재달·다음2달을 확인한다. 모든 과거 공지나 영구 미래 일정을 전수 수집한다는 의미는 아니다. 성공적으로 확인한 월의 삭제/이동된 캘린더 항목은 교체한다. 조회 범위 밖의 이전 기록은 보존한다. 공지 목록은 제한된 범위이므로 이전 공지 삭제의 완전 감지를 보장하지 않는다.

사이트 새로고침/5분 갱신은 저장된 서버 자료만 읽는다. 소스별 최근 성공시각과 실패/지연을 구분한다. 신규 소스가 없는 기존5소스 피드도 읽을 수 있어 롤아웃 중 접근 오류를 막는다. 게시 정책은 여전히 승인된 공지 작성자만 허용하며 NAVER 일반 검색을 재활성화하지 않는다.

회원/관리자/공사중/법률문서/미르/공용라우터/시크릿은 변경하지 않는다. `/web/_isegye_idol/.schedule-feed`의 기존 제한된 데이터 발행만 사용한다. 공개 열람 방법이 변경되거나 서비스측 요청이 있으면 수집 중단 및 원문 안내로 전환한다.
