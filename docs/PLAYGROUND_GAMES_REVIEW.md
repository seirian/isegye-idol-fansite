# 놀이터: 신규 3종 콘텐츠 검토

검토 브랜치 `feature/playground-games`. 기준 `37fcb9490e40a337a473881d0dc24e7401956d59`.
검토 주소는 기존 관리자 전용 `/review-playground/`를 재사용한다. 기존 검토본 파일은 불변 릴리스로 보존하고 이전 포인터도 별도 백업한다. 운영 `/#/playground`, main/develop, 기존 80문항 기본은행·일배치·계정·저장함은 변경하지 않는다.

## 동작

- **응원봉 링크**: 6×6 격자에서 같은 색/기호 3개 이상, 가로·세로·대각선 연결. 20번 이동, 시간제한 없음. 길게 연결할수록 추가 점수. 여섯 색을 각 6개 모으면 무대 완성 +500점, 나머지는 다음 무대에 이월. 막힌 판 자동 재배치. 키보드·하나씩 누르기·드래그·터치, 힌트/취소, 한국 날짜에 따른 고정 판/자유 판/같은 판 공유. 새로고침 이어하기.
- **별빛 캐치**: 60초 좌우 이동. 별 기본10점, 5콤보마다 보너스(최대20), 프리즘 기본30점과 5초간 획득 두 배. 운석 −30(최저0), 잠깐 중복 충돌 보호. 누락은 콤보만 초기화. 고정 시간 간격 시뮬레이션과 동일 seed 패턴, 키보드·터치·마우스·화면 좌우 버튼. 일시정지/탭 이탈 자동 정지, 재도전, 개인 최고 기록. 새로고침 때 진행 중 액션은 새 판으로 시작한다.
- **나만의 콘서트**: 기존 공식 원본 매핑 중 25곡(초기 검토 기준)에서 중복 없이 8곡. 이름/멤버/음반/별칭 검색, 참여 구성 필터, 오프닝1곡·본공연5곡·앙코르2곡 순서 편집, 제목과 3개 자체 테마. 실제 PNG 카드 저장, 텍스트 및 URL fragment 공유, 다른 구성 가져오기 전 확인. 공유 보기만으로 기존 초안을 덮어쓰지 않는다.

## 데이터와 권리 범위

미니게임 그래픽은 자체 CSS/Canvas 도형, 효과음은 직접 합성한 짧은 전자음이며 기본 꺼짐이다. 팬아트, 공식 캐릭터·응원봉 디자인 복제, 멤버 목소리, 가사, 음원, 방송 캡처, 썸네일은 사용하지 않는다. 외부 이미지·오디오 파일이나 외부 게임 에셋도 없다.

콘서트 데이터는 `catalog/music.json`, `catalog/video-sources.tsv/json`, `catalog/album-releases.json`의 **공식 채널**로 검증된 원본 링크를 골라 최소 필드(곡 ID·제목·참여 멤버·음반명·별칭·원본 URL·자료 확인일)만 사용한다. 팬 백업과 노래방 영상은 제외한다. 기존 자료 확인일을 유지하며 이번에 원본 전체를 새로 재생·감상하거나 권리 허락을 받은 것으로 표시하지 않는다. 글 설명·위키 본문·이미지를 복사하지 않는다. 감상은 원본 새 탭 링크이며 음원 추출·다운로드·배경 재생·자동 재생은 없다. 실제 곡 전체나 최신 수록곡 전체를 제공하는 카탈로그라는 주장은 하지 않는다. 검토본에 추가 배치나 외부 수집을 연결하지 않았다.

결과 카드에는 비공식·개인 제작 세트리스트와 실제 공연이 아니라는 문구를 넣는다. 원작 제목을 제외한 카드 배경·텍스트 구성은 자체 작성. 공유 링크는 검토 단계에서 관리자에게만 열린다.

## UI와 기록

운영 메뉴와 같은 글꼴 스택·테마 토큰·제목 규칙(`review-2nd/polish.css`)을 재사용한다. 새 상단 보조 메뉴나 공개 랭킹은 없다. 320px부터 PC까지 검사한다. 색상과 기호 병기, 키보드 조작, 감소된 동작 설정, 명시적 일시정지·음소거 제공.

기록 키는 `isegye:review:playground-games:v1`. 운영 퀴즈·저장함과 분리. 저장 차단·손상 시 현재 탭에서 계속 플레이하며 경고. 초기화는 이 키만 변경. 새 게임·가져오기·초기화에 확인창. 공개 업로드/댓글/계정 동기화 없음. 공유 fragment는 페이지 요청 시 서버로 전송되지 않지만 이용자가 복사한 링크에는 선택한 제목과 곡 ID가 포함된다.

## 배포 경계

`playground-games-preview.yml`은 feature 브랜치에서만 작동한다. 비밀정보 없는 검증 단계에서 단위/패키징/PHP 관리자 권한/실제 HTTP 브라우저 검사 및 PNG 생성 후 HTML 해시를 고정한다. 게시 단계는 기존 직렬 실행 그룹과 중지 변수를 준수하고 동일 해시만 게시한다.

게시기는 현재 운영 릴리스·인증 엔트리·게이트웨이·이전 검토본과 다른 검토 포인터를 대조한다. 기존 `PlaygroundPreview.php`가 정확히 일치하고 계정 접근 게이트 뒤에 있을 때만 `.review-playground/releases`에 불변 파일을 올려 `active.json`을 원자적으로 바꾼다. 서버 재읽기·익명 접근 차단·운영 화면 불변 검사가 실패하면 직전 검토 포인터로 복구한다. 인증 코드·루트 라우팅·계정 저장소·문제은행을 쓰거나 실제 회원 로그인 세션을 만들지 않는다.

공식 기술 참고: MDN Pointer Events 및 Web Audio best practices(2026-11-18 검토). 사용자의 동작에서만 소리를 활성화하며 외부 라이브러리 의존 없이 구현했다.
