workflow_dispatch로 요청하므로 원래 일시정지/접근/검증/공통 쓰기 직렬화가 적용된다.

## 독립 점검
GitHub 내부 예약 보충만으로 GitHub 예약 이벤트 자체의 누락은 해결할 수 없다.

외부 점검도 지연될 수 있으며 모든 정각 실행을 보증하지 않는다. 최근 상태/실제 게시
산출물로 성공을 확인하며, 설정 추가만으로 정상화 완료라고 보고하지 않는다.
