사용자는 앨범에 등록된 모든 곡의 기록일 보완, develop·main 반영 및 운영 배포를 승인했다.

가이섬 곡 상세의 최고 순위 요약에는 달성일이 없지만 각 차트의 공개 순위 추이에는 날짜와 시간이 있다. 최고 순위 요약을 유지하면서, 동일한 멜론 곡 ID·앨범 ID·차트 종류·순위를 확인한 추이만 별도의 `melonPeakDates` 근거로 연결한다. 이전 출처의 날짜와 기존 과거 자료는 조회 구간을 정하는 단서로만 사용하며 실제 날짜는 가이섬 추이 응답에서 다시 검증한다.

## 전곡 대조 결과

## 기록일 의미

- `date`는 확인한 추이에서 해당 최고 순위가 나타난 날짜다. 시간별 차트는 한국시간 관측 시각을 보존하고, 일간 차트는 날짜 단위로 표시한다.
- 조회 자료에 공백이 있을 수 있으므로 전기간 최초 달성일이라고 주장하지 않는다. 같은 순위가 여러 번 나오면 확보한 근거 중 가장 이른 시점을 사용한다.
- 요약 순위가 바뀌거나 곡·앨범·차트가 다르면 이전 기록일을 새 순위에 붙이지 않는다. 확인되지 않은 날짜는 추정하지 않는다.
- TOP100, HOT100 30일·100일, 실시간, 일간, 최신발매 1주·4주는 별도로 검증한다. 멜론 연결이 없는 영상 전용 항목에는 순위나 날짜를 만들지 않는다.
- 날짜의 출처 URL, 실제 확인 시각, 응답 SHA-256, 조회 범위를 보존한다. 카드의 출처 링크를 다시 추가하지 않고 기존 ‘최고 성적 출처와 확인 시각’ 안에서 근거를 제공한다.

## 수집 및 운영 반영

검증된 초기 날짜 자료는 `albums/peak-reference/guyso-dates-20261118.json`에 저장한다. 정기 앨범 배치가 같은 순위의 날짜 근거를 보존하도록 연결하며, 변경된 순위의 날짜는 제한된 추이 조회로 검증한다. 매시간 전곡의 과거 구간 전체를 다시 수집하지 않는다. 배치 예약 및 새벽 수집 중지 정책은 유지한다. 배포용 정적 자료에도 현재 등록된 24곡의 검증된 참조와 기록일을 포함한다. 기존 승인 스냅샷에 없는 최근 5곡에는 확인된 곡 식별자와 참조만 보충하며 공식 API 조회 성공·좋아요·시계열 관측값을 만들지 않는다.

운영 UI 배포가 성공한 뒤 전용 유지보수 작업이 현재 앨범 피드의 날짜 근거만 보완한다. 공통 운영 쓰기 직렬화, 앨범 잠금, 기존 바이트 비교, 백업, 게시 후 재조회와 실패 시 복구를 사용한다. 차트 시계열·순위 요약·수집 기준 시각·회원 데이터는 변경 대상이 아니다. 배포와 데이터 게시 성공은 각각의 실행 및 재조회 결과로 확인한다.
