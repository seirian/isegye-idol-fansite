# 이세돌 별빛 배송부

## 열 곳을 잇는 야간 배송

여섯 멤버 중 한 명을 골라 소인 광장에서 마지막 환승역까지 편지를 배달한다. 열 개의 배송지에는 각각 한 장의 전용 배경, 출발점, 우체통, 마감 시간이 있다. 카메라와 미니맵은 현재 무대를 보여준다. 화면 가장자리 표식으로 편지·보스·우체통의 방향을 찾을 수 있다.

| 배송지 | 필요한 편지 | 봉인된 우체통 |
| --- | ---: | --- |
| 1. 소인 광장 | 8 | |
| 2. 바람개비 골목 | 10 | |
| 3. 유리온실 길 | 12 | |
| 4. 닻을 내린 부두 | 14 | 먹물 닻지기의 돌진을 옆으로 피한다. |
| 5. 반딧불 수로 | 16 | |
| 6. 달빛 인쇄소 | 18 | |
| 7. 종탑 우체국 | 20 | 유리종 소프라노의 고리 파동을 건넌다. |
| 8. 유성 철교 | 22 | |
| 9. 새벽 활주로 | 24 | |
| 10. 마지막 환승역 | 28 | 반송왕 제로의 부채꼴 공격과 순차 폭발을 피한다. |

모두 배달하려면 편지 172통이 필요하다. 보스 배송지에서는 편지를 채우고 보스를 쓰러뜨린 뒤 해당 우체통에 닿아야 배송을 마친다. 이동하며 가까운 적에게 자동으로 별탄을 쏘고 대시와 멤버 특기는 직접 사용한다. 봉투의 소인에 따라 짧은 보호막, 특기 대기시간 감소 또는 점수 보너스를 받는다.

5번째 배송지부터는 봉인 소포가 깨지며 작은 적들이 흩어지고, 8번째부터는 사선 특급이 이동 방향을 예측해 돌진한다. 바닥의 예고선이 고정되는 순간 방향을 바꾸거나 특기로 돌진을 끊을 수 있다. 결과 화면에서 배송 등급과 최고 콤보, 쓰러뜨린 보스 수, 마지막으로 도달한 우체국을 확인한다.

첫 아홉 번의 배송 뒤에는 장비 세 가지 중 하나를 고른다. 카드에는 장비 그림과 이름, 효과 한 줄이 표시된다. 가방의 ‘진화 조합 보기’를 펼치면 유성 펜촉과 분류 날개로 얻는 관통 공격 등 모든 조합의 효과를 확인할 수 있다.

장비를 고르면 다음 배송지의 출발점으로 이동한다. 새 배경과 배송지 이름이 보이는 동안 제한 시간이 멈추고, 소개가 끝나면 새 편지와 적이 있는 무대에서 출발한다. 장비·진화·체력·점수는 이어지고 이전 무대의 공격이나 일시 효과는 끝난다.

### 출발 난이도

멤버를 고르는 화면에서 출발 전에 난이도를 바꿀 수 있다. 첫 방문은 쉬움이며, 다음 방문과 재도전 때는 선택한 난이도를 이어간다. 최고 점수와 최근 배송은 난이도마다 따로 보관한다. 이전 버전의 점수는 쉬움 기록으로 이어받는다.

| 난이도 | 적의 이동 속도 | 주의할 공격 |
| --- | ---: | --- |
| 쉬움 | 기존 속도 | 이전 버전의 적과 보스 패턴 |
| 보통 | 쉬움보다 18% 빠름 | 젤리가 표시된 직선을 따라 도약한다. 보스는 첫 공격에 이어 측면이나 퇴로를 공격한다. |
| 어려움 | 쉬움보다 36% 빠름 | 주술 적이 현재 위치와 이동 방향 앞에 소인을 차례로 찍는다. 보스는 양쪽에서 시간차로 후속 공격을 보낸다. |

### 보행과 멤버 특기

각 멤버는 한쪽 발을 디디고 반대쪽 발을 앞으로 가져오는 네 장의 보행 그림과 두 발을 땅에 붙인 정지 그림을 사용한다. 실제로 이동한 거리에 따라 보폭이 진행되며, 대시 때는 다리를 뻗고 잔상이 남는다.

아이네의 보호막은 별이 박힌 수정 테두리, 징버거의 감속은 시계판, 릴파의 질주는 펼쳐지는 날개로 표시된다. 주르르의 자석은 편지와 이어지는 하트, 고세구의 밀쳐내기는 바깥으로 퍼지는 구름, 비챤의 회복은 새잎으로 구분한다. 기기의 모션 감소 설정을 사용해도 멤버별 효과 모양을 볼 수 있다.

로비와 플레이 화면은 사이트에 저장된 밝은 화면·어두운 화면 설정을 따른다. 설정에서 ‘기기 설정에 맞춤’을 선택할 수도 있다. 제목과 장비 이름에는 주아체, 설명과 조작 안내에는 고운돋움을 사용한다. 이파리 연대기와 동일한 글꼴 파일과 SIL Open Font License 전문을 게임에 포함하며, 두 라이선스는 설정에서 읽을 수 있다.

**설계 참고.** 적이 몰리는 동안에도 이동에 집중할 수 있는 자동 공격과, 한 판 안에서 장비 조합을 실험하는 구조를 참고했다. 배송부에서는 같은 우편을 모아도 공격 장비를 챙겼는지, 대시나 특기를 강화했는지에 따라 후반 돌파 방식이 달라진다. ### 로컬 실행과 검사

```sh
python scripts/build_courier_production.py --preview
python -m http.server 4178 --bind 127.0.0.1 --directory test-results/courier-preview
```

`http://127.0.0.1:4178/`에서 바로 플레이한다. HTML에 장비·지도·보스 그림을 포함한다. 노선 도중에 탭을 닫으면 해당 판은 끝난다. 기존 최고 점수·선택 멤버·소리 설정은 유지하며 최근 배송 결과를 같은 브라우저에 저장한다.

```sh
node --test tests/courier-engine.test.js
python -m unittest discover -s tests -p test_courier_production.py -v
python tests/courier_campaign_browser.py
```

브라우저 검사는 Chromium과 Python Playwright를 사용한다. 키보드 이동과 버튼 선택으로 열 곳을 돌고 결과 화면에서 재도전한다. 320·390·768px 터치 화면, 외부 요청, CSP 위반, 기존 기록 호환성도 검사한다. 스크린샷·HTML 체크섬·검사 결과는 `test-results/courier-campaign/`에 남는다.

2026-11-25 엔진 검사 20개와 패키징 검사 14개가 통과했다. 여섯 멤버가 세 난이도에서 각각 보스 세 명을 쓰러뜨리고 열 번째 배송까지 완주했다. 같은 여덟 시드와 멤버 여섯 명을 조합한 자동 플레이에서 판당 피격 횟수는 쉬움 2.54회, 보통 3.54회, 어려움 3.96회였다. 같은 입력으로 이전 버전과 쉬움을 비교한 여섯 판의 점수·피격·완주 시간도 일치했다.

Chromium에서 보행과 정지 자세, 멤버별 특기, 난이도 선택과 재도전, 기존 기록 호환, 열 개 무대를 확인했다. 390px 터치 화면에서도 보통으로 보상을 선택하고 다음 무대에 입장했다. 운영 경로 형식으로 로컬 검증한 HTML은 8,088,717바이트이며 SHA-256은 `458a707c4fcd13696745e57ace122fcebdf7466bb0b1527b99406e618a815215`다.

## 폐기와 배포 범위

이전 세 게임의 소스와 화면 탐색을 제거했다. 과거 Git 커밋과 기존 서버의 불변 릴리스는 배포 복구 기록으로 남으며, 새 활성 검토본에서는 제공하지 않는다.

검토 주소: https://isegye-idol.kr/review-playground/
브랜치: `feature/isegye-fangames`.

새 이미지까지 단일 HTML의 data URI로 포함하며 외부 연결 없는 해시 CSP를 유지한다. 기존 관리자 인증 경로를 재사용하고, `.review-playground` 내 릴리스와 활성 포인터만 게시한다. 운영 놀이터 메뉴 통합은 검토 후 별도 단계이다. 이전 퀴즈 기록·계정·배치·운영 UI를 읽거나 수정하지 않는다.

저장 키는 `isegye:review:courier:v2`이며 선택 멤버·효과음 설정·최고 점수만 해당 브라우저에 저장한다. 저장 불가/손상 시에도 플레이 가능하다.

## 검증

```sh
node --check fangames/engine.js
node --check fangames/app.js
node --test tests/courier-engine.test.js
python scripts/build_fangames.py
python -m unittest discover -s tests -p test_fangames.py -v
python tests/fangames_browser.py
```

단위 검증은 재현 가능한 게임 시뮬레이션과 경계·상태 전이를 확인한다. 브라우저 검증은 HTTP에서 실제 UI 조작, 캐릭터 이미지, 키보드와 터치, PC·모바일 레이아웃, 일시정지·저장·결과 흐름을 확인한다. 게시 완료는 Actions 성공만이 아니라 `review-fangames-deployment.json`의 `gated_preview_published_and_verified`, 실제 게시 바이트 재조회, 기존 운영 및 인증 격리 유지 확인으로 판단한다. 실제 사용자 계정을 가장해 로그인하지 않는다.

2026-11-18 로컬 최종 검증: 엔진 9개, 빌드·배포 격리 12개, 브라우저 88개 검사를 통과했다. 실제 키보드 입력으로 3회 배송·2회 강화·4455점 A등급 승리를 확인했고, 320/390/768/1440px 화면과 1280×720 결과 버튼 클릭을 검증했다. JavaScript/CSP 오류와 외부 요청은 0건이다. 브라우저 검증 HTML SHA256은 `e2dd2c375ba5b95fbb991206ae3fa5b48ad03bf3e6d422be62a59377402d1c55`이며, 검사 동안 빌드 바이트가 바뀌지 않았다.
