## 표시 및 수집

상단 ‘멜론 최고 성적’에 TOP100, HOT100(100일), 실시간, HOT100(30일), 일간, 최신발매(1주), 최신발매(4주)를 각각 표시합니다. 앞의 3종은 주요 카드, 나머지 4종은 보조 카드이며 원 사이트의 UI를 복제하지 않습니다.

일간은 검증된 멜론 원본을 우선하고, 확인되지 않는 차트별 최고는 정확한 멜론 곡 ID·앨범 ID·곡명·가수를 대조한 이세계차트 공개 관측 기록으로 보완합니다. 보조 기록은 별도 melonPeakFallback 필드에 저장하며 원본 melonPeaks 필드를 덮어쓰거나 공식 기록으로 표시하지 않습니다.

각 항목에 순위, 기록일(제공될 때), 출처 링크를 표시하고 접을 수 있는 표에 확인 시각을 제공합니다. 누락값은 —이며 수집 실패 시 검증된 동일 곡·앨범의 이전 값만 기존 확인 시각 그대로 보존합니다. 최근 30일 그래프의 최저 숫자나 예측값을 역대 최고에 넣지 않습니다.

확인 예: KIDDING의 TOP100 6위, HOT100(100일) 2위, 실시간 2위, HOT100(30일) 1위, 일간 41위, 최신발매 1주/4주 각각 1위. 출처: https://isegyechart.com/song/799 (일간은 멜론 원본 우선).

## 접근과 범위

보조 요청은 https://isegyechart.com/song/<검증된 ID> 만 허용하며 쿠키·인증값·우회 헤더를 사용하지 않습니다. 응답 크기·타임아웃·호스트·리디렉션을 제한합니다. 가사·디자인·이미지·원 사이트의 시계열 전체를 저장/복제하지 않으며 최고 순위 사실과 기록일·신원·출처만 저장합니다. 이용허락이나 제휴 계약을 확보했다고 주장하지 않습니다.

현재 검토 workflow의 push/수동 실행에서만 수집합니다. 정기 수집의 신규 활성화 및 운영 반영은 이번 변경에 포함하지 않습니다. 새 곡은 곡 ID 매핑과 원본 신원 대조를 거쳐야 추가됩니다.
