제1조 (처리 목적·항목·근거와 보유기간)

회원 기능 제공에 꼭 필요한 정보만 처리합니다. 회원 원장의 영구 저장, 인증 중 일시 처리, 로그인 세션, 브라우저 저장 및 문의 처리를 구분합니다.

현재 사이트의 개인정보 처리 내역
구분·목적항목과 처리 범위처리 근거보유·삭제 기준

Google 인증 검증ID 토큰, 원본 sub, 이메일 및 이메일 확인 여부, 서명·발급자·대상·유효기간·일회용 검증값. 토큰에 이름·프로필 사진 등의 정보가 포함될 수 있으나 회원 원장에는 저장하지 않습니다.같은 법 제15조제1항제4호: 로그인 요청 처리인증 요청 처리 중 메모리에서만 사용하고 종료 후 별도 보관하지 않습니다. 이메일은 지정 관리자 확인에 일시 사용합니다.
로그인 유지·요청 위조 방지세션 쿠키, 서버 세션의 변환 식별값·CSRF 검증값·발급/활동 시각·로그인 전 일회용 nonce같은 법 제15조제1항제4호: 안전한 인증 기능 제공로그아웃 시 해당 세션 삭제. 인증 유효기간은 최대 12시간, 비활동 30분이며 로그인 전 nonce는 10분입니다. 만료 시 인증에 사용할 수 없고 잔여 세션 파일은 서버 정리 과정에서 삭제합니다.
기기별 편의 설정즐겨찾기 항목 ID와 화면 테마를 해당 브라우저에 저장. 회원 원장과 연결하거나 서버로 동기화하지 않습니다.이용자가 선택한 기능 제공. 서버 수집과 구분이용자가 설정을 바꾸거나 사이트 저장정보를 삭제할 때까지 해당 기기에 남습니다.
문의·권리 행사이용자가 이메일로 보낸 회신 주소·요청 내용과 필요한 최소 본인확인 정보. 회원 원장과 별도로 문의 메일에서 처리합니다.요청 처리에 필요한 경우 같은 법 제15조제1항제4호, 법적 의무 이행이 필요한 경우 제2호요청 목적 달성 후 지체 없이 삭제합니다. 법률상 보존 사유가 있으면 근거·대상·기간을 확인하여 필요한 범위만 분리 보관합니다.

회원 원장에는 이름, 이메일 주소, 사진, 원본 sub, Google 토큰, IP 주소, User-Agent, 가입·최근 로그인 이력을 저장하지 않습니다. 사이트 비밀번호, 주민등록번호, 결제정보도 수집하지 않습니다. 다만 변환 식별값도 같은 회원을 알아보는 정보이므로 “완전 익명” 또는 “개인정보를 전혀 처리하지 않음”으로 설명하지 않습니다.

운영 애플리케이션은 별도의 방문·광고 추적 로그를 만들지 않습니다. 호스팅 서버의 접속·보안 로그에는 IP, 요청 시각·주소, 응답 상태와 브라우저 정보 등이 기록될 수 있습니다. 해당 로그의 구체적인 보관기간은 호스팅 약정·운영 설정을 확인해야 하며, 확인되지 않은 기간을 임의로 단정하지 않습니다. 문의 시 확인 가능한 처리 기준을 안내합니다.

제2조 (수집 경로)

  1. 이용자가 Google 로그인 버튼을 선택하면 Google의 인증 결과를 사이트 서버에 전달하여 확인합니다.
  2. 로그인 유지와 보안 요청 검증 과정에서 필요한 쿠키·세션 정보가 생성됩니다.
  3. 즐겨찾기·테마 선택 시 해당 브라우저에서 저장정보가 생성됩니다.
  4. 운영자에게 이메일을 보내거나 외부 GitHub에 직접 요청을 게시한 경우 해당 경로로 문의 내용이 전달됩니다.

기본 검색어는 브라우저의 URL 해시와 화면에서 처리하며 별도 검색 이력으로 저장하지 않습니다. 이 방침은 방문자·회원 정보의 처리 기준이며, 아티스트의 공개 활동 자료에 대한 출처 표시는 각 콘텐츠에서 별도로 제공합니다.

제3조 (만 14세 미만 이용자)

현재 회원가입은 만 14세 이상을 대상으로 하며, 만 14세 미만을 위한 법정대리인 동의 절차는 제공하지 않습니다. 나이 확인을 위해 생년월일이나 신분증을 수집하지 않으므로 Google 인증만으로 사이트가 이용자의 연령을 확인했다고 보지 않습니다.

만 14세 미만 회원의 개인정보 처리 사실이나 법정대리인의 요청을 확인하면 필요한 본인·대리권 확인 후 삭제 등 적절한 보호조치를 합니다. 단순 공개 정보 열람과 회원가입은 구분합니다.

제5조 (제3자 제공)

회원 원장의 식별값과 권한을 판매하거나 광고·마케팅 목적으로 제3자에게 제공하지 않습니다. 이용자의 별도 동의 또는 법령상 근거가 있어 제공해야 하는 경우에는 그 근거와 범위에 맞춰 처리합니다.

외부 로그인·이미지·방송 조회 또는 외부 링크를 이용하면 이용자의 브라우저와 해당 사업자 사이에 접속정보가 전달될 수 있습니다. 이는 운영자가 회원 원장 전체를 전달하는 것과 구분하며, 제7조에서 실제 연동을 설명합니다.

호스팅 제공자의 자체 로그·백업 보존 기준과 서버의 물리적 처리 위치는 계약·운영 설정으로 별도 확인할 사항입니다. 사이트가 직접 확인하지 않은 삭제 주기나 국가를 확정된 사실처럼 표시하지 않습니다.

제7조 (외부 연동과 국외에서의 처리)

다음 기능은 외부 사업자와 직접 통신합니다. 사업자별 정책을 확인할 수 있도록 연결하며, 로그인이나 외부 미디어 이용을 선택하지 않는 방법도 안내합니다.

현재 사이트가 회원 원장을 별도 해외 DB로 복제·동기화하는 기능은 없습니다. 새로운 국외 처리위탁·보관·제공을 도입할 때에는 수신자, 국가, 항목, 시기·방법, 목적·기간, 적용 근거와 거부 방법을 확인하여 안내하고 법령상 필요한 절차를 먼저 이행합니다. 외부 사업자의 직접 수집과 운영자의 국외 이전에 관한 의무를 동일한 것으로 간주하지 않습니다.

제8조 (분석·광고 추적의 사용 여부)

현재 사이트에는 Google Analytics, 광고 추적 픽셀 또는 맞춤형 광고 쿠키를 설치하지 않았습니다. 방문 행동 분석을 목적으로 회원 식별값과 조회 기록을 결합하지 않습니다.

Google 로그인과 외부 썸네일·LIVE 조회에 필요한 통신은 있을 수 있으므로 “외부로 아무 정보도 전송되지 않는다”는 의미는 아닙니다. 새로운 분석 도구를 도입하면 수집 항목·목적·보유기간·거부 방법과 필요한 동의 절차를 별도로 안내합니다.

제9조 (파기와 보존 예외)
